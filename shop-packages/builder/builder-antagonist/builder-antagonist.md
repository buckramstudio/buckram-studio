# Builder: antagonist

Fill-in builder worksheet for Chat about (Library pack).

## Light

Job: make opposition load-bearing — person, system, nature, or Lie-as-force.

Contract: fill before outlining Act Two; revisit when obstacles feel random. If the force vanished, the protag Want should not succeed immediately.

Must-not-break (worksheet-only):

- Protagonist external goal is binary / checkable
- Goals are **mutually exclusive** — if both can “win,” conflict is soft; redesign
- Obstacles chain from one agenda
- Present at major structural beats (not Act-Two ghost)
- Attacks the hero’s greatest weakness
- Climactic defeat of outer force ↔ inner Lie/Truth turn
- Reader briefly thinks “what if they’re right?” (temptation quality)

## Hard

**Named schools / distinctions**

- **Antagonist vs villain** (Weiland): opposition need not be morally reprehensible; upright opposition still blocks Want
- **Truby opponent**: same/mutually exclusive goal + attacks greatest weakness; hidden plan structures reveals
- **Lie avatar**: outer pressure designed to press inner Need/Lie 
- **Mirror Mapping**: Lie ↔ antag Truth/extreme + parallel wound + shared collision surface

**Opposition stress test** (Agent mode)

- Mutually exclusive goals + pressure-on-Lie map
- Does antag move first this stretch?
- Credible win path still open at midpoint?

**Advanced diagnostics**

- Symptom: mid-book drift → pressure map empty at Midpoint / All-is-lost
- Symptom: climax feels unearned → Plan steps never paid on page
- Contagonist job: tempt or delay without replacing primary force

**When to break “personified face”**

- System / nature / society as force: still fill Want/plan as agenda of the system; optional human avatar for scenes; still name influence web

**Handoff / scope**

- **Produces:** force card + Mirror Mapping + plan / influence web + pressure map.
- **Next:** outline / plot pressure beats; cast grid if the personified face is load-bearing (, ).
- **Not this sheet:** protag Origin Scene; romance HEA contract; full GMC theory essay .

**Methods cited:** Weiland antagonist vs villain; Truby opponent (shared goal + greatest weakness); Mirror Mapping (Lie ↔ antag Truth/extreme). Paraphrased — not a substitute for the primary texts.

**Refuse:** no “mean because bad”; no Act-Two ghost; Chat verbs are operational patterns, not craft law.
