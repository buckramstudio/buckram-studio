# Builder: series

Fill-in builder worksheet for Chat about (Library pack).

## Light

Multi-book arc + promise tracking worksheet. Theory → .

Must-not-break (worksheet-only):

- Series end-state known enough to avoid Book-2 drift
- Book 1 satisfaction-first, then tease
- Growth sticks unless new justified pressure
- Promise ledger reviewed before outlining next book
- Avoid pure no-payoff cliff as the only ending pattern
- Pitch/spine ≠ living production bible — keep both current
- If it isn’t in the bible, it isn’t canon by next book

## Normal

**Order of use**
1. Spine (pitch) + Living bible header
2. Nested arcs
3. Promise ledger
4. Per-book progression grid
5. Continuity stubs + change log + Forbidden list
6. Launch / exit checklist

## Hard

**Type-specific edges**
- Episodic: series arc optional — still ledger character growth that must stick
- Standalone-connected: each book’s promise ledger is mostly local; shared bible is continuity stubs only
- Sequential trilogy: nested arcs required; Book 2 midpoint of series often darkest

**Advanced diagnostics**

| Symptom | Cause | Fix |
|---------|-------|-----|
| Middle-book sag | No local meal; only series tease | Progression grid “local plot” |
| Growth resets | Soft continuity | Stick unless new pressure |
| Orphan foreshadow across books | No deadline | Payoff due Book __ |
| Retcon from memory | No log / Forbidden | Continuity log + named locks |

**When to break “know the end”**
- Discovery writers: know series *question* and Forbidden locks even if end-state sketch is one sentence
- Don’t outline Book 5 in full before Book 1 satisfaction exists

**Handoff / scope**
- **Produces:** series spine (pitch) + living bible header + promise ledger + Forbidden / continuity locks.
- **Next:** Book N outline / cast state dump / world locks (, , ).
- **Not this sheet:** single-book beat maps; scene cards; full world encyclopedia.

**Methods cited:** Series bible pitch vs living production bible; promise ledger (plant → progress → payoff); Forbidden / continuity-log practice. Paraphrased — not a substitute for the primary texts.
**Refuse:** no pure no-payoff cliff as the only ending pattern; no inventing Book N+1 canon past Forbidden locks; Chat verbs are operational patterns, not craft law.
