# Builder: voice

Fill-in builder worksheet for Chat about (Library pack).

## Light

Job: one sheet per major character so covered-name dialogue still identifies the speaker.

Contract: differentiate ≥3 dimensions; freeze at intro; re-check mid-draft for drift. Prefer **diagnostic** audits over generative “write as this character forever.”

Must-not-break (worksheet-only):

- Consecutive-dialogue read mid-MS: still one person
- Attribution test: 10-line exchange trackable without tags
- Blind spots / wrongness specified (not universal EQ)
- Distinct from narrator register (if close POV)
- One accent + one tic per book (anti-caricature)

## Normal

**Order of use**

1. Identity anchors
2. Five dimensions (differentiate ≥3)
3. Six ingredients + voice extensions
4. Word lists
5. Speech behavior
6. Constraint drills (optional training wheels)
7. Same-stimulus samples
8. Fingerprint paragraph
9. Diagnostic prompt pack (audit, don’t generate)
10. Drift checklist

**1. Identity anchors**

- Name / role Age / era / region Education / class / culture
- Occupation / expertise Emotional default at rest Stress emotion when speaking

**2. Five dimensions**

| Dimension | Fill |
|-----------|------|
| Vocabulary register — ceiling / floor | ___ |
| Sentence architecture — short / long / fragment / subordinate | ___ |
| Relationship with certainty — assert / hedge / analyze | ___ |
| What they suppress | ___ |
| Content focus — what they notice first | ___ |

**3. Six ingredients:** Emotional default Diction Syntax Rhythm & pace Formality Catchphrases & tics (≤2–3)

**Voice extensions** (beyond the six)

| Extension | Fill |
|-----------|------|
| Metaphor domain (profession/hobby supplies comparisons) | ___ |
| Silence pattern (when they refuse; silence as power) | ___ |
| Self-referential vs other-focused | ___ |
| Thought-process in speech (logical / distractible / stream) | ___ |

**[example stub]** Fingerprint micro-fill (constraint / metaphor / silence — not a scene)

| Slot | Fill |
|------|------|
| Constraint (training wheel) | Never asks a direct question under stress |
| Metaphor domain | Dockyard / cargo / weather windows |
| Silence pattern | Wins arguments by letting the other fill the quiet |

**4. Word lists (Leonard-style)**

- Words they reach for (10) Words they never use (10)
- Slang / idiom / multilingual pepper Metaphor preferences Humor style

**5. Speech behavior**

Direct vs oblique Assertive vs passive Proactive vs reactive Questions vs statements Interrupt habits Voice when scared / in love / lying

**6. Constraint drills** (training wheels → then relax, keep rhythm)

Pick one drill per practice pass: no questions no contractions ≤5-word sentences must deflect with questions. Draft a short exchange under the constraint; then rewrite relaxing the rule while keeping the rhythm/idiolect.

**7. Same-stimulus samples**

Write in voice (no tags):

1. Bad news reaction (2–4 lines)
2. Same line three ways — “I don’t have time for this.”
3. Argue about [topic] (3–5 exchanges with another fingerprint)

**8. Fingerprint paragraph (100–200 words)** — paste finished card

**9. Diagnostic prompt pack** (do **not** generate new dialogue unless asked)

Use with fingerprint cards visible:

- **Voice consistency:** two samples from same character → match/conflict on diction, syntax, fillers
- **Differentiation audit:** untagged lines → assign speakers from fingerprints only
- **On-the-nose detector:** flag emotion stated directly; propose subtext alternatives
- **Speech pattern builder:** background → map range/length/fillers/region — *no dialogue generation*
- **Subtext:** what each wants from the other beyond literal talk

Optional cadence: keep fingerprint visible while drafting; run bleed audit every N scenes.

**10. Drift checklist**

- ☐ Written at intro Mid-MS consecutive dialogue still one person
- ☐ Attribution test without tags Blind spots specified Distinct from narrator
- ☐ Metaphor domain + silence pattern filled for majors
- ☐ One accent + one tic ceiling held

| Failure | Fix |
|---------|-----|
| All speakers merge | Force ≥3 dimension diffs |
| Catchphrase cosplay | Cut to ≤2–3; deepen diction/syntax |
| Late fingerprint only | Write at intro; re-audit mid |
| Tags every 2–3 lines (attribution bleed) | Widen dimensions; re-run cover-names; healthier ≈ tags every 4–6 (heuristic) |
| Voice only in slang | Add metaphor domain + silence + certainty relationship |

## Hard

**Edge: narrator vs character**

- Close POV: narration borrows character diction — still keep dialogue more extreme than thought
- Omniscient / distant: character fingerprints live mainly in dialogue; don’t force narrator into every tic

**Stress-state spectra**

- Map scared / in love / lying as *deltas* from default — not three unrelated voices
- Lying often increases hedge or over-assert — pick one pattern per character

**Ops (anti-bleed)**

- One major character = one fingerprint doc in context; multi-character single agent → bleed
- Prefer plan constraints → draft → voice-keeper edit pass over “RP as character”
- Separate planning directive from prose generation when Agent-assisted

**Advanced diagnostics**

| Symptom | Cause | Fix |
|---------|-------|-----|
| Tags required to know who speaks | Dimensions too similar | Widen ceiling/floor + notice focus |
| Voice only in slang | Register costume | Syntax + certainty + metaphor domain |
| Mid-book blend | No re-inject | Drift checklist + diagnostic pack |
| Attribution every 2–3 lines | Bleed / flat dimensions | Differentiation audit; deepen extensions |

**Handoff / scope**

- **Produces:** fingerprint card (dimensions + extensions + word lists) + diagnostic audit checklist.
- **Next:** cover-names pass on draft dialogue; cast voice tags; bleed audit mid-MS .
- **Not this sheet:** full scene drafting; generative “RP as character forever”; romance beat contracts.

**Methods cited:** WHW six-ingredient voice; Career Authors metaphor / silence extensions; Lowe diagnostic fingerprint audits. Paraphrased — not a substitute for the primary texts.

**Refuse:** no catchphrase costume; no celebrity mimicry; diagnostics beat generative oracle; Chat verbs are operational patterns, not craft law.
