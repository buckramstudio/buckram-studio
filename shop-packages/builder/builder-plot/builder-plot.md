**But / therefore chain (anti–“and then”)**

1. List every plot event in 1 line (whole book ≤ ~3 pages).
2. Between each pair, force a connector: **but** / **therefore** (or cut).
3. Reject **and then** chains (episodic default).
4. Ask: if I remove this event, does the ending still work? If yes → dead wood.

**[example stub]** Short but/therefore chain (5 beats — placeholders)

1. Protag needs a travel stamp → **but** clerk demands a name.
2. **therefore** Protag asks Ally to vouch → **but** Ally is the ledger thief.
3. **therefore** Midpoint: Protag names Ally under pressure → **but** trust breaks.
4. **therefore** dark night: stamp is useless without Ally’s route → **but** Ally won’t speak.
5. **therefore** climax answers Inciting: get the stamp *without* becoming the clerk’s kind of person — or refuse the stamp.

Reject if any link is **and then** with no cost.

**Coincidence & false-stakes traps**

| Pattern | Catch | Fix |
|---------|-------|-----|
| Coincidence *starts* trouble | Usually OK | Keep; tighten causality after |
| Coincidence *resolves* climax / saves MC | DEM / unearned | Plant earlier; make MC choose; pay a cost |
| Stakes stated once, never escalate | Middle deflates | Refresh risk/reward meaning; add urgency or moral cost — not only bigger explosions |
| False stakes (threat never paid) | Reader learns to ignore danger | Either pay or strategically delay with visible cost of delay |
| Fun & Games = flavor loop | Middle wanders | Each premise-delivery scene adds rule / cost / skill / failure / emotional complication |

Weiland rule of thumb: coincidence violates cause-effect; if used, foreshadow so it doesn’t feel dropped from orbit.

**STC middle strip (diagnostics, not a second beat sheet)**

- **Fun & Games:** each premise-delivery beat adds rule / cost / skill / fail / emotional complication
- **Midpoint:** false win *or* false loss + clock / urgency shift (still victim→warrior)
- **Bad Guys Close In:** polarity opposite Midpoint (if Mid was false win → pressure collapses; if false loss → temporary hope then crush)

**Act inventory (optional depth)**

- **Act One (~25%):** ordinary world + empathy inciting desire thematic question moral dilemma external goal refusal flaw mentor plan change antagonist reveal no return
- **Act Two (~50%):** obstructed steps deepen relationships secrets action↔reflection pinches subplots
- **Act Three (~25%):** process loss reason to persevere new plan final confrontation succeed by giving something up forever changed day-after image

| Failure | Fix |
|---------|-----|
| Soft midpoint | Force reactive→proactive flip |
| Climax ≠ Inciting question | Bookend rewrite |
| Resolving coincidence | Plant + agency + cost, or cut rescue |
| Flavor-only Fun & Games | Add rule/cost/skill/fail/emotion per beat |

## Hard

If romantic leads: track Romance Arc beside external plot and each internal arc .

**Structure generators**

- Three-act breakdown: premise → per act opening state, 3–4 events, act-ending turn, emotional trajectory
- Midpoint reversal: first-half summary → 5 reactive↔proactive flips
