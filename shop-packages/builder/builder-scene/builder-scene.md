# Builder: scene

Fill-in builder worksheet for Chat about (Library pack).

## Normal

**Draft / revision checklist**
- [ ] What happens (one sentence) Motivation (need/want + why)
- [ ] Most pressing thing replaces the big thing
- [ ] Opposition: 3 hurdles Reaction → synthesis → action
- [ ] Change or Reveal 3× conflict Tension (unresolved questions)
- [ ] Snapshot — one sticky picture Momentum — why NOW?
- [ ] Relevancy to REAL story conflict Fulfills premise promise
- [ ] Ends with unresolved conflict (or clear turn)

Aim ≥3 major scene elements; avoid info-dump-heavy scenes.

Keep conflict on the Goal — don’t wander into decorative obstacles.

| Failure | Fix |
|---------|-----|
| MRU whip-saw | Split Motivation / Reaction paragraphs |
| Pretty but off-spine | Relink Goal ↔ story question |

## Hard

**Story Grid Five Commandments** (editor overlay on GCD — not a replacement)

| Commandment | Fill | Pass? |
|-------------|------|-------|
| Inciting Incident | Causal ☐ / Coincidental ☐ — what destabilizes? | |

| Crisis | Best Bad Choice ☐ / Irreconcilable Goods ☐ — binary with cost | |
| Climax | Choice enacted under pressure (reveals who they are) | |
| Resolution | Meaningful consequence of that choice | |
| Value shift | ___ → ___ (genre value) | |

Same beat on GCD (optional cross-check): Goal = get stamp; Conflict = clerk + Ally ask; Disaster = “yes but” trust cost.

**Commandment failure traps**

- Inciting does not promise / mirror climax
- Turning point is a random drop-in, not progressive failure of strategy
- Crisis options don’t flow from the turning point
- TP / Crisis / Climax switch protagonists
- Resolution invalidates Crisis stakes (no cost)

**Cast to visualize (optional)**

For each present: interesting appearance clothes express character meaningful object where’s the flash of color?
Roles: MC Antagonist Ally Romantic interest Mentor Nemesis Gang Non-human roadblocks.

**Edge cases**
- Disaster ≠ catastrophe: quiet “yes but” can escalate stakes without explosion
- Sequel on-page vs compressed: thrillers often compress; emotional romance often dramatizes Reaction
- Multi-POV: missing Sequel knowledge → next Goal feels unmotivated even if prose is fine
- Causal vs casual: plot is not a sequence of events — Sequel Decision must motivate next Goal

**Advanced diagnostics**

| Symptom | Cause | Fix |
|---------|-------|-----|
| Throat-clear scene | No Goal at open | GCD card |
| Emotional whiplash | MRU order broken | Feeling→Reflex→Speech |
| Pretty but inert | No Change/Reveal | Cut or add turn |
| Sticky image missing | All abstract emotion | Flash-of-color object |
| Soft Crisis | No binary cost | Best-bad / irreconcilable goods |
| Random TP | Strategy never exhausted | Progressive complication rewrite |

**Handoff / scope**
- **Produces:** filled GCD and/or 5C card for one unit.
- **Next:** Sequel Decision → next Scene Goal; stage card if place pressures Want ; chapter promise check .
- **Not this sheet:** world bible; full beat-sheet cosmology replacing GCD.

**Methods cited:** Ingermanson / Swain GCD + Sequel + MRU; Story Grid Five Commandments (editor overlay); Bickham scene revision (disaster list; goal↔story question). Paraphrased — not a substitute for the primary texts.
**Refuse:** 5C overlays GCD — does not replace it; no first-disaster reflex as craft; Chat verbs are operational patterns, not craft law.
