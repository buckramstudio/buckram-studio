# Builder: Magic system

Fill-in rules + cost/limits worksheet. Theory → (Sanderson laws) .

## Light

Job: one sheet per magic (or tech-as-magic) system before it solves plot problems.

Contract: ability to solve conflict with magic ∝ reader understanding (First Law); expand before add (Third Law).

Must-not-break:
- Hard/middle/soft dial named
- More limit rows than power rows
- Cost that forces a character choice (not just HP drain)
- New power at climax forbidden unless foreshadowed
- Magic may create problems freely; solving climax needs rules already shown
- Tempted to add a second system? Deepen ramifications first

**Chat-about verbs** (when iterating this sheet)
- **Intake** — lane / story need / locked rules before inventing powers
- **Fill** — elevator → dial → L/W/C rows
- **Stress-test** — find loopholes; villain uses; society’s counter-rules
- **One-rule cascade** — pick one cost (“costs years of life”) → full downstream effects
- **Canon paste** — re-attach current rule rows; do not invent past what is locked
- **Canon-lock** — after Book N, dump M-rules + first-shown + open exploits for Book N+1

**Handoff / scope**
- **Produces:** one system sheet (dial + L/W/C + access + ripples) + optional M-rule lock table.
- **Next:** world bible stubs for culture ripples ; series continuity for multi-book locks .
- **Not this sheet:** full secondary-world encyclopedia; scene blocking.

**Methods cited:** Sanderson laws (esp. limitations / costs / expand-don’t-add); hardness = reader understanding. Paraphrased — not a substitute for the primary texts.
**Refuse:** no invented universal hardness scales beyond reader-understanding; no unexplained solve-by-magic; Chat verbs are operational patterns, not craft law.

**Edge cases**
- Soft-magic story: magic creates problems / wonder; solving via unexplained magic breaks trust
- Soft without scale benchmarks: tension floats — set candle-vs-fire early even if rules stay mysterious
- Hard-magic story: if reader can’t invent the clever solution, dial was soft in practice
- Tech-as-magic: same sheet — treat constraints as “physics the cast lives inside”
- Multi-system temptation: Third Law — interconnect and streamline before inventing new

**Advanced cost design**
- Antagonist-weaponizable costs create plot without new powers
- Social / moral cost (taboo, licensing, stigma, guilt) often stronger than material drain for series arcs
