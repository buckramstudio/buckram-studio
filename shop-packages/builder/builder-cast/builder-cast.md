## Hard

**Spine vs democracy**

- Ensemble still needs a primary engine Want — “everyone equal” often means no climax focus
- Multi-POV: max simultaneous POVs is a design constraint, not a virtue

**Weiland large-cast compress**

- Distinct concrete goals related to protag goal
- Ally conflict required
- Lump similar → spokesperson
- Action beats > dialogue tags for differentiation

**Archetype / function edges**

- Contagonist ≠ second antagonist — temptation/delay job
- Foil shares goal, opposite method — different from ally; run foil protocol
- Jung role labels optional; function checklist first

**When to break the grid**

- Intimate two-hander → skip ensemble grid; use / romance couple
- Phone-book world cast for color only — don’t put tourists on the load-bearing grid

**Handoff / scope**

- **Produces:** ensemble contract + cast grid + Event×Cast reactions + foil / worldview maps.
- **Next:** per-person cards / relationship sheets / outline beats that use cast jobs (, , ).
- **Not this sheet:** full Origin Scene / GMC depth; antagonist Mirror Mapping; voice fingerprints.

**Methods cited:** Weiland large-cast compress; Susannah Waters Event × Cast (secondary-as-protagonist); foil protocol. Paraphrased — not a substitute for the primary texts.

**Refuse:** no phone-book casts; no spectators at climax; Chat verbs are operational patterns, not craft law.
