# Builder: relationship

Fill-in builder worksheet for Chat about (Library pack).

## Light

Job: make a load-bearing bond generate scenes — status, intimacy, chemistry triad, and conflict patterns, not labels.

Contract: fill when the pair/triad carries Act Two pressure; revisit when chemistry never appears on the page.

Must-not-break (worksheet-only):

- Each person has a Want outside the dyad
- Bond changes visible in behavior, not labels
- At least one irreversible trust/betrayal beat
- Lead interactions move ≥1 of {Friction, Recognition, Stakes}
- Triangle: neither option is a strawman
- Gottman patterns = conflict craft lexicon — not therapy advice on the page
- Romance HEA engine → also use 

**Methods cited:** weak `builder-relationship` bond/GMC/status/intimacy/triangle/ledger; Romance 101 chemistry triad + swap test; Desire/Risk/Knowledge tension model; Gottman Four Horsemen → fiction tells + antidotes (character-cast-voice hunt). Paraphrased — not craft law / not therapy.

**Refuse:** fanfic trope laundry lists as chemistry; therapy dump into prose; Chat verbs are operational patterns, not craft law.

**Swap-partner diagnostic:** replace partner → if scenes still work, chemistry is generic — rewrite triad fills.

**Chemistry engines** (weak worksheet — keep)

- ☐ Contrast (tempo / belief / skill gap)
- ☐ Banter type: warm / sarcastic / professional / silent competence
- ☐ Shared secret / debt
- ☐ Forced proximity / mutual enemy
- ☐ Status flip scenes planned
- ☐ Withdrawal beats as intimate as approach

**Desire / Risk / Knowledge** (tension model)

- Desire evolves across scenes (curiosity → trust → need to be known)
- Risk rises with intimacy
- Knowledge gaps create charged restraint
- Resolution costs something and answers the fear that kept them apart
