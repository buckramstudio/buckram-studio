# Builder: premise

Fill-in builder worksheet for Chat about (Library pack).

## Normal

**Order of use**
1. Lane lock
2. Story vs situation gate
3. Premise anatomy (Lyons) → premise sentence
4. Logline / elevator
5. GMC one-pager (protag + antag)
6. One-page plot spine (5 beats)
7. Go / no-go + objective unit-test

**1. Lane lock**
- Obligatory moments this shelf requires

**[example stub]** When / Acts / Until skeleton (generic placeholders — not a pitch)

> When **[Constriction]** forces **[Protag]** to act, **[Protag]** **[Acts]** with/against **[Focal]** until **[Resistance]** creates chaos, leading to **[Change]**.

Filled once (swap freely):
> When the clerk freezes their travel stamp, **Pat** must name an ally or lose the route, until the ally’s enemies close in, leading **Pat** from peace-by-omission to costly honesty.

Story-vs-situation kill on same stub: obvious fix (“just name them”) fails because Change is the point — situation-only would end at the stamp.

**4. Logline (appeal filter)**

- Target length often **25–35 words**; no proper names unless fame is the hook; goal / obstacle / stakes — don’t Twitter-hook the sell-twist
- Optional Anne R. Allen phrasing: `When X happens to Y, they must Z or face W`
- Elevator pitch (≤50 words / ~15 sec)
- Starts with protagonist? Visualizable? Stakes specific? Ends before Act Three? ≤4 characters named?

**5. GMC one-pager**

Spine: *[Protag] wants [G] because [M]. But [C], while [Antag] wants [G2]…*

**6. One-page plot spine (5 beats)**

1. Setup / ordinary world
2. End of Act One (no return)
3. Midpoint (shift / false victory / truth)
4. End of Act Two / dark night
5. Climax + resolution (spoilers OK here)

**7. Go / no-go + objective unit-test**

- ☐ **Unit-test:** 3–4 experienced readers (not mom): Do they see whole spine? Would they write it? More passes than thumbs-up → fix or abandon before outlining

| Failure | Fix |
|---------|-----|
| Mushy middle later | Revisit spine beats 2–4 |
| Logline spoils ending | Cut Act Three |
| Comps incoherent | One edge stated |
| Soft logline | 25–35 words; When/must/or-face; drop names |

## Hard

**Premise vs logline vs synopsis (don’t collapse)**
- Premise tests engine (conflict + stakes + hook + change)
- Logline filters appeal (tease, visual, short — not a Twitter twist pitch)
- Synopsis sells structure (not this card’s job — see if present)

**Foolscap / controlling-idea edge**
- Obligatory moments from shelf must not contradict controlling idea
- Age dial changes what “stakes specific” means (kidlit vs adult)

**Antagonist force without person**
- GMC still fills: Goal of the force, Motivation (why pressure now), Conflict (what blocks protag)
- If force has no Motivation, stakes feel random — invent institutional Want

**Handoff / scope**
- **Produces:** lane lock + premise sentence + logline + GMC spine + 5-beat one-pager.
- **Next:** outline / Snowflake expand (, ) after go/no-go.
- **Not this sheet:** full synopsis; beat-by-beat chapter draft; pub query package .

**Methods cited:** Jeff Lyons premise anatomy (When/Acts/Until/Leading-to; story vs situation); Dixon GMC; agent/editorial logline norms (Chappelle / Anne R. Allen phrasing). Paraphrased — not a substitute for the primary texts.
**Refuse:** no situation dressed as story; no inventing unit-test reader verdicts; Chat verbs are operational patterns, not craft law.
