# Builder: character

Fill-in builder worksheet for Chat about (Library pack).

## Light

Job: fill cards that force Want, wound, and challengeable beliefs before drafting the person.

Contract: mains need beliefs that crash into plot; side characters can stay rough.

## Normal

**Order of use** (worksheet depth beyond people track table)

1. Quick attribute checklist
2. Generation template
3. Wound → shield → need (or Lie/Truth/Want/Need/Ghost)
4. Origin Scene (misbelief that *felt smart*)
5. Want taxonomy (optional depth)
6. Six Things That Need Fixing
7. GMC book + scene
8. Per-scene tracker

Wound chain (behavior-first): wound event → protective fears → dysfunctional habits → unmet need → fatal flaw that blocks goal. Shielding is what they *do*, not what they “are.”

**Fatal-flaw protocol (order)**

1. Name wound → Lie / misbelief that *felt smart then* → list shielding
2. Pick cognitive block that most blocks the goal
3. Pick matching behavioral tripwire
4. Design failure patterns + small wins (or tragic refusal)

Cron-compatible option: treat “fatal flaw” as **misbelief that saved them short-term** — not victim framing alone.

**Origin Scene** (after Lie/Truth — scene, not another table cell)

Misbelief bumper-sticker (one sentence the story will falsify): ___

1. Brainstorm moments where that belief *saved* them short-term.
2. Write Origin as a short scene (or beat sheet): place time external event internal shift X→Y sensory tell.
3. Trace forward: every major scene pressures the misbelief via a tough decision.
4. Climax resolves the internal lens first; external win is consequence.

## Hard

**Contradiction / motivation generators**

- Contradiction: [role] holding [belief 1] and [belief 2] — rationalization → when it breaks → forced choice
- Motivation mapper: stated goal → say they want / actually want / need / afraid of getting / would destroy them if got
- Arc planner: across [N] chapters — misbelief → 3 turning points → almost-regress → final transformation

**CP bridge (Motivation mapper → scene audit)**

For any sticky scene action: bridge spine → this beat — Why this decision? Follows prior beat? Fits who they are? (Full consistency audit below.)

**Character Consistency Audit** (Fiction Yogi / WHW — Agent CP mode)

1. **Spine:** beginning person drive core wound what growth looks like
2. **Scene choices:** Why this decision? From prior beat? Fits who they are?
3. **Emotional echo:** after big events, next scene carries residue (or earns numbness)
4. **Voice isolation:** dialogue/narration still them after trauma?
5. **Growth not replacement:** mid/end — original personality remains under change

Also ask: emotion enough? Flaw visible? Dialogue realistic? Consistent to stimuli? Empathy hook (even dark leads)?

**Personality sketcher (messy → tool-ready)**

- Input: rich description → organized third-person sketch; dispassionate; no chat chrome

**Edge: arc-type mismatches**

- Flat arc: Want ≈ Need; world changes around them — don’t force Lie→Truth beat map
- Fall / Corruption: Truth abandoned — Ghost still installed the starting Lie
- Antagonist GMC must pressure protag Want — foil without private engine = cardboard

**Handoff / scope**

- **Produces:** GMC + misbelief bumper + Origin slots + Six Things plant list.
- **Next:** cast Event×Cast / relationship sheets; outline beats that pressure the lens (, ).
- **Not this sheet:** 140-trait exams; full romance beat contracts ; antagonist Mirror Mapping .

**Methods cited:** Cron Origin Scene / misbelief; Weiland Lie–Truth / Ghost; Dixon GMC. Paraphrased — not a substitute for the primary texts.

**Refuse:** no 140-trait dumps as the sheet’s spine; no invented universal personality cosmologies; Chat verbs are operational patterns, not craft law.
