# Builder: stage

Fill-in builder worksheet for Chat about (Library pack).

## Normal

**Order of use**
1. Stage card (per scene / major set)
2. Setting-pressure checklist
3. Character-style place analogues (if load-bearing)
4. Maass experience keys
5. Atmosphere palette

**Stage card** (worksheet depth beyond discuss scene card)

| Field | Fill |
|-------|------|
| Place name / shorthand | |
| Time of day / season / weather (material, not caption) | |
| Who belongs here / who is watched | |
| Exits / barriers / sightlines | |
| Threat geometry (crowd / emptiness / darkness / thin walls) | |
| Sensory fingerprint for this POV (2 priority; prefer non-visual first) | |
| Recurring sensory motif (if any) | |
| How place changes what they do / say / feel this scene | |
| How place creates or blocks the scene goal | |
| How antagonist (or force) can *use* the place | |
| Mood constraint on speech/movement | |
| Describe-while-acting beat (blocking, not postcard paragraph) | |

**Setting-pressure checklist**
- [ ] Location creates or blocks a goal this scene
- [ ] Same argument would play differently in kitchen vs church vs garage (**swap test**)
- [ ] Antagonist can use the place
- [ ] Climax (or this beat) needs this geography
- [ ] After midpoint: place changed *or* perception changed
- [ ] Details arrive while characters act — not as a tourist opener
- [ ] Pressure aims at Desire (place punishes the Want’s shortcut)
- [ ] Blindfold geometry: reader can navigate exits/sightlines/social rules without guidebook dump

If all “no,” stage is backdrop — stop overwriting it.

**Character-style place analogues**

| Character tool | Stage / place fill |
|----------------|--------------------|
| Personality + backstory | History/culture “rules” of how it behaves |
| Interiority | Mood; secrets; iconic recognizers |
| Conflict | Environment as obstacle/enabler |
| Arc | Place changes *or* perception changes |

**Atmosphere palette**
- Sensory palette filtered by POV
- Social temperature
- Threat geometry
- Motifs that teach mood without naming “ominous”

Pathetic fallacy: OK when close POV honestly warps nature; trap when omniscient weather matches every beat. Prefer material pressure (heat, mud, curfew) *plus* possible misread.

| Failure | Fix |
|---------|-----|
| Five-sense dump | Prioritize two for POV |
| Weather caption mood | Material pressure + POV filter |
| Wallpaper stage | Swap test fail → pick an obstacle lever |
| Guidebook open | Blindfold geometry; show rules in action |

## Hard

**Load-bearing place vs stage**
- Recurring geography / travel catalog → 
- This card is blocking space for *one* scene’s Want
- Stage ≠ Location: durable bible facts stay on location cards; don’t dump series geography here

**Generator hooks** (prompt residue — use sparingly)
- Setting as character: 5 genre settings as antagonist/ally — one paragraph + how each shapes plot
- Sensory immersion: location/time — prioritize two senses; one foreshadowing detail
- Obstacle course: pick 2 levers from the taxonomy; force Goal through both

**When to break “two senses”**
- Spectacle set-pieces may widen palette — still filter through POV stress ( if present)

**Methods cited:** Maass setting-as-pressure; Writers Helping Writers obstacle-course taxonomy (danger / misfortune / roadblock / people / micro). Paraphrased — not a substitute for the primary texts.

**Refuse:** no travelogue wallpaper; Stage ≠ Location (no series geography dump here); Chat verbs are operational patterns, not craft law.
