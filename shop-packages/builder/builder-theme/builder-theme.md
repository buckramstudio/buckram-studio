# Builder: theme

Fill-in builder worksheet for Chat about (Library pack).

## Light

Theme argument + motif ledger (fill-in). Theory → .

## Normal

**Order of use**
1. Theme contract
2. Lie ↔ Truth beat anchors
3. Thematic square (cast pressure)
4. Motif ledger
5. Dilemma → theme bridge
6. Anti-sermon audit
7. One-line theme card for packets

**1. Theme contract**
- Story / series Subject / topic (1–2 words)
- Thematic question (debatable) Working Truth
- Protagonist Lie Need Controlling idea at ending (embrace / reject / pyrrhic)

**3. Thematic square** (McKee labels)

| Stance | Character | Scene where they press |
|--------|-----------|------------------------|
| Truth (positive value) | ___ | ___ |
| Contradiction / Lie (opposing value) | ___ | ___ |
| Contrary (tempting gray / rival good) | ___ | ___ |
| Negation² (negation of the negation / cynic extreme) | ___ | ___ |

☐ No unanimous chorus converting on cue each major stance has a character ☐

**4. Motif ledger**

| Motif | First plant (ch) | Mid echo | Payoff / flip | Charge |
|-------|------------------|----------|---------------|--------|
| ___ | ___ | ___ | ___ | ___ |

Rules: accumulate then flip ☐ each return changes context ☐ No caption dialogue ☐ Removable without climax change → cut ☐ 
Silence / pacing may carry theme — not every beat needs a motif caption.

**5. Dilemma → theme bridge**

- Hard fork that proves Truth/Lie
- Option A costs Option B costs Easy third path blocked how (on-page)

**6. Anti-sermon audit**
- ☐ Cut author thesis lines — climax still argues?
- ☐ Supporting cast disagrees without all converting?
- ☐ Motifs silent; plot loud? (silence/pacing ok)
- ☐ Ending statement matches the choice paid for?
- ☐ Topic words in blurb ≠ theme proven in MS

**7. One-line theme card**
> Theme: ___ Lie: ___ Truth: ___ Motifs: ___ Do not sermonize; prove via ___

| Failure | Fix |
|---------|-----|
| Motif wallpaper | Require flip / charge change; trust silence |

## Hard

**Ending modes that change the card**
- Embrace Truth Reject Truth Pyrrhic — controlling idea line must match paid choice
- Disillusionment / Fall arcs: Truth may be bitter; don’t force positive slogan

**Cross-lane**
- Romance: Truth often about worthiness / trust — couple Black Moment must pressure Lie 
- Mystery: thematic aftertaste optional; don’t let sermon replace fair-play solution

**Advanced diagnostics**

| Symptom | Cause | Fix |
|---------|-------|-----|
| Theme only in dialogue | No dilemma bridge | Hard fork with costs |
| Cast agrees too soon | Missing contrary/negation | Fill thematic square |
| Motifs captioned | Author anxiety | Show flip; cut explanation; allow silence |
