# Controlled mythic

## What this method changes

Create scale and timeless weight through elemental nouns, formal cadence, archetypal pressure, and selective figurative language held inside strict budgets.

**Narrator priority:** Name the material world clearly, enlarge only what carries moral or communal weight, and return every abstraction to action, object, body, or consequence.

## Best fit

Foundational conflict, ritual, landscape, inheritance, journeys, communal memory, and moments where individual action touches a larger order.

## Hard limits

**Anti-caricature:** Scale earned by consequence. Most action sentences plain. Formal widening only for thresholds/vows/communal stakes/irreversible choices/aftermath.

- Do not use pseudo-archaic pronouns/verb endings/indiscriminate inversions.
- Do not stack epithets/kennings/metaphors/symbolic nouns.
- Do not personify every natural element.
- Do not make unsupported universal claims.

## Apply behavior

Install previews the pack in Library. Apply to Style Filters replaces only the targets listed in apply-manifest.yaml after confirmation.
