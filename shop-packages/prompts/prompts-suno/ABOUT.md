# Suno

Custom Mode wrap — style field (no brackets) plus lyrics tags. Write the song first; this kit only formats Suno paste.

Installing this craft kit adds focused guidance into your project Library. It steers outlining, drafting, or revision toward the topics below — exact Agent use depends on how the pack is wired after install.

**What it tends to cover**
- `prompts-suno.md`
- `suno-lyrics-tags.md`
- `suno-style-prompt.md`
- `suno-paste-templates.md`
- `suno-failure-modes.md`

If **Song lyrics** is also installed, write the song there first. Do not mix this kit with Udio, ElevenLabs Music, or Mureka tags in one paste.

**Tags:** prompts, music, suno

Open **About this pack** any time before or after install. After install, use the Files list to read notes and turn off pieces you do not want attached.
