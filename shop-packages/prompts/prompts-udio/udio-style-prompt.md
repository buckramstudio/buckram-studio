# Udio — prompt (style)

Prompt describes the **song**, not the lyric grammar.

## Shape

Topic + comma-separated genres (and optional mood / vocal).

```
late kitchen blues, dark electric blues, spare, male vocal
```

```
summer dance-floor hit, dance-pop, bright, female vocal
```

## Do

- Lead with the topic (what the song is about) when it helps
- Comma-separated genres
- Vocal hint in the prompt, not as a fake lyric tag

## Don’t

- Paste the full lyric into the prompt
- Square-bracket structure tags in the prompt
- A paragraph of production theory
