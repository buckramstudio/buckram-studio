# Udio — lyrics tags

Published autocomplete list. Guidance, not hard-coded commands. Spellings are locked — do not “fix” them to Suno’s.

## Published list

`[Verse]`, `[Chorus]`, `[Intro]`, `[Outro]`, `[Bridge]`, `[Hook]`, `[Pre-chorus]`, `[Refrain]`, `[Post-chorus]`, `[Drop]`, `[Interlude]`, `[Instrumental Break]`, `[Instrumental]`, `[Build]`, `[Pre-hook]`, `[Pre-drop]`, `[Pre-refrain]`, `[Break]`, `[All]`, `[Breakdown]`, `[Instrumental Bridge]`, `[Sample]`, `[Solo]`, `[Ensemble]`, `[Post-hook]`, `[Spoken Word]`, `[Choir]`, `[Announcer]`

## Use

- One tag per line, then the lyric lines for that section.
- `/` in the host lyrics box shows this list.
- Prefer this list over invented tags. Experimenting is allowed; don’t replace the list.

## Hyphenation

Official: `[Pre-chorus]`, `[Post-chorus]`, `[Pre-hook]`, `[Pre-drop]`, `[Pre-refrain]`, `[Post-hook]`.

Not Suno: `[Pre-Chorus]`, `[Post-Chorus]`.

## Don’t

- Treat tags as guaranteed section commands
- Mix Suno parameterized `[Verse: whispered vocals, …]` as the default here
- Put genre lists inside lyrics tags
