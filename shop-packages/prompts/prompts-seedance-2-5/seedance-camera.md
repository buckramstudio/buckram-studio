# Seedance 2.5 — camera vocabulary

Drive **how we see** the stage. Pair with `seedance-staging.md`. Continuity → `seedance-continuity-30s.md`.

**Target:** 2.5 only. Prefer confirmed 2.5 move vocabulary; tag Uncertain terms.

## Light

Job: one clear camera plan the model can hold for the whole clip (or per stage).

Contract: **name the move**; say who it orbits/follows; say when it starts and stops.

Must-not-break:
- Camera clause ≠ subject-action clause (two independent axes)
- One dominant camera idea unless stages change it on purpose
- **One move per shot / beat** — don’t stack push + pan + tilt + orbit in the same beat
- Vague “cinematic / dynamic” does not steer
- Niche term → also describe observable picture change

## Normal

### Shot size

Use clear English shot-size words and framing direction.

| Term | Use for |
| ------ | --------- |
| Wide / full | Full body + environment |
| Medium | Waist-up / interaction |
| Close-up / medium-close | Face, hands, product |
| Extreme wide | Geography, scale |
| Extreme close-up | Micro detail |

### Angle / viewpoint

| Term | Effect |
| ------ | -------- |
| Eye-level | Neutral, conversational |
| Low angle | Subject dominates |
| High angle / overhead / top-down | Map view, layout |
| First-person / FPV / micro-FPV | Body-mounted / flight path |
| Dutch angle | Unease |

### Movement keywords

**Prefer these first:**

| Keyword | What happens |
| --------- | -------------- |
| Slow push-in | Camera moves toward subject |
| Pull-back / pull out | Camera moves away |
| Steady lateral track / parallel tracking | Sideways with subject |
| Follow | Trails subject; state height |
| Arc / circle / circular pan | Circles subject |
| Handheld / handheld gimbal tracking | Organic path; name who is followed |
| Whip-pan | Fast yaw; state trigger |
| Crane / boom / rise–descend | Vertical path |
| Dive | Aggressive downward path |
| Static / locked-off | No camera move |
| Dolly zoom / Vertigo | Dolly + opposite zoom |
| Bullet time / bounce / speed ramp | Freeze/slow + snap |

Formula for uncommon terms:

`[term] + [target] + [how picture changes] + [fg/bg relationship] + [direction or speed]`

Example: *Rack focus: shift focus from foreground leaves to the person behind; leaves soften; face goes soft → sharp.* (**Rack focus**: craft / **Uncertain** as official enum.)

### Cuts vs continuous

| Mode | Prompt habit | Maker note |
|------|----------------|------------|
| **Narrative one-take** | “continuous single take”, “no cuts”; one camera path | Seed 2.5 blog |
| **Planned cuts / timed joins** | Name join; keep axis; use timestamp windows |
| **Montage / coverage** | Explicitly ask for varied angles/inserts |

### Screen-space framing

| Specify | Example |
|---------|---------|
| Subject’s third of frame | “keep red player in left third; hoop stays right” |
| Height | “chest height behind”, “door-height parallel track” |
| Axis lock | “never cross the court axis” |
| Move trigger | “camera does not pan until the ball has left both hands” |
| Settle | “camera stops inside the store” |

### Prefer / avoid

| Prefer | Avoid |
|--------|-------|
| slow steady push-in from medium to close-up | zoom in cinematically |
| parallel tracking left→right, subject centered | dynamic camera |
| crane up from medium to high wide | epic reveal |
| restrained handheld medium close-up | shaky documentary (no subject) |
| static locked-off; all motion from walk + coat flare | camera somehow follows somehow |
| one named move this beat | push + pan + tilt + orbit together |

### Duration vs camera complexity

| Duration (2.5 hosts) | Camera budget |
|----------------------|---------------|
| 4–5s | One move or locked; one beat |
| ~8s | One arc (e.g. track + small settle) |
| ~15s | 2–3 timed camera beats |
| ~30s | Stages; change camera only when a stage needs it |

## Hard

**Name camera first** when the shot must not become “subject wiggles because frame was static.”

**Separate axes:**

```
Camera: slow ninety-degree orbit, subject stays centered.
Subject: three controlled kettlebell swings, chest-height apex, steady rhythm.
```

**Multi-subject frames:** always say who the move is built around.

**Optics extras (optional):** 35mm natural perspective, deep focus / shallow DOF, anamorphic look — describe the visible result. (**Uncertain** as official optics vocabulary.)

| Failure | Fix |
|---------|-----|
| Drift / float | Lead with concrete move + locked subject position |
| Camera + subject mush | Split clauses; simplify to one move |
| Cut chaos on narrative | Switch to single take + no cuts |
| Montage needed but flat | Explicitly request varied angles/inserts |
| Fancy term ignored | Keep term + translate to visible change |
| Stacked moves in one beat | Drop to one named move |

**Uncertain:** synonym coverage for niche terms (e.g. “truck” vs “lateral move”). Prefer the confirmed terms above when unsure.
