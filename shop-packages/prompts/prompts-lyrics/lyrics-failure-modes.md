# Lyrics failure modes

Job: name the break, then fix **that** axis. Do not rewrite the whole song for a line-length miss.

## Light

Must-not-break:
- No prose in line breaks
- No chorus denser than the verses
- No abstract chorus with zero images in the verses
- No 50/50 palette blend; no three palettes stacked
- No host tags when no host kit is attached
- No **wrong** host tags (Suno paste with Udio spellings, etc.)

## Normal

| Don’t | Do |
|-------|-----|
| Paragraphs chopped into lines | 6–10 word lines; one stress-group each |
| Chorus that explains the plot | Chorus = promise; verses = evidence |
| Title only in the last bar of verse 2 | Title in the chorus landing |
| “Cinematic / epic / emotional” as lyric | Concrete object + action |
| Mixing blues AAB with a pop pre-chorus and a rap verse | One palette; name a one-line override if needed |
| `[Whispered]` / `{guitar solo}` / Udio `[Pre-chorus]` with no host kit | Plain `[Verse]` / `[Chorus]` |
| Two host kits’ tags in one paste | One host wrap after the song exists |
| Inventing a through-composed form for “summer hit” | V–C–V–C–B–C |
| Fortune-telling “#1 next July” | Pop / dance-pop hit form |
| Diegetic snatch only, no full lyric | Excerpt **plus** full song underneath |

### Symptom → first fix

| Symptom | Likely cause | First fix |
|---------|--------------|-----------|
| Unsingable mouthful | Prose line | Cut to 6–10 words; split |
| Chorus forgotten | Dense / no title | Simplify; put title on the hold |
| Verses interchangeable | No images | One named object per verse |
| Genre mush | Two palettes | Pick nearest; one override line |
| Host ignores structure | Missing or wrong tags | Wrap with the attached host only |
| Scene quote feels unfinished | Snatch without full song | Print both |

## Hard

Change **one** variable per rewrite when the song is mostly right (rhyme **or** image **or** form — not all three).

If a host kit is attached, do not “improve” its tag spellings from another host.
