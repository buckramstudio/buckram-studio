# Palette — Sea shanty

Call-and-response **work song**. Not a pop chorus stack.

## Form

Call line, response line, repeat. Verses can be work-list images. Refrain is the work shout. Optional last call that names shore.

## POV

We. Crew. I only if one sailor calls and we answer.

## Line density

Short. Call shorter or equal to response. Breath for hauling.

## Rhyme

Work-song repeat. Perfect rhyme welcome. Internal bounce OK.

## Imagery bank

Rope, swell, watch, shore, salt, night helm, a name of a ship (original), rum only if it earns, wind.

## Chorus job

The response. Title is what we shout while we work.

## Refuse

- Pop V–C–V–C–B–C stack as default
- Power-ballad climb
- Pirate-cartoon dictionary dump (`yo-ho` every line) unless the brief is comedy (name it)

## Mini example (original)

Title: **Haul, then hold**

```
[Call]
Wind on the wrong cheek —
[Response]
haul, then hold

[Verse]
Watch says three and the swell says more
rope burns a map in my palm
Shore is a rumor with a warm name
we don't spend it yet

[Call]
Name her kind when we see the light —
[Response]
haul, then hold
```
