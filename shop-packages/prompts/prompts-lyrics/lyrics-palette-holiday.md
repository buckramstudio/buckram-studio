# Palette — Holiday

One ritual + **one honest crack**. Not a generic calendar greeting.

## Form

V–C–V–C–B–C. Chorus can be warm. Bridge is the crack (empty chair, unpaid bill, the person missing). Then chorus again — earned.

## POV

We / you. Family or chosen-family room.

## Line density

Chorus: singable, 6–8. Verses: the room. Name the ritual (tree, meal, heat wave barbecue — holiday is not only snow).

## Rhyme

Warm perfect rhymes on chorus. Don’t force “year / cheer” unless it’s actually good.

## Imagery bank

Kitchen, tree **or** heat, snow **or** porch fans, one empty chair, a dish that’s always made, a song the house plays, wrapping paper, a light left on.

## Chorus job

The ritual named simply. Title can be warm; verses supply the honest crack so it isn’t an ad.

## Refuse

- Generic “it’s Christmas” with no room
- Pure cynicism with no ritual (that’s indie spite, not holiday)
- Chart-hit dance-pop unless the brief is a holiday banger (then name Pop as override)

## Mini example (original)

Title: **Set an extra plate**

```
[Verse]
The gravy boat still waits
like it didn't get the year
Your chair faces the window
we don't move it here

[Chorus]
Set an extra plate
we don't have to say why
Set an extra plate
the house still sets a life
```
