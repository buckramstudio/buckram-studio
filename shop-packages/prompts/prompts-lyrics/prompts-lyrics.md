# Song lyrics

Write a **singable song** from the brief. This kit does not teach host extras (Suno, Udio, ElevenLabs, Mureka). If a host kit is attached, wrap with **that** host after the song exists.

Prompt-only. No APIs, no Buckram auto-render.

## Companions

| File | Use when |
|------|----------|
| `lyrics-brief-decoder.md` | Pick one palette from the brief (index always on) |
| `lyrics-form.md` | Section jobs; do not invent a form for a hit |
| `lyrics-hook-title.md` | Title = promise; hook repeatable and slightly incomplete |
| `lyrics-singability.md` | Line length, stress, vowels, chorus rhyme |
| `lyrics-failure-modes.md` | Prose-as-lyrics, dense chorus, mixed palettes, wrong host tags |

Palette files (`lyrics-palette-*.md`) start **off**. Use the decoder index when they are off. If the matching module is enabled, use that file’s depth.

## Light workflow

1. Decode the brief → **one** palette (`lyrics-brief-decoder.md`, then the enabled deep file if any).
2. Lock **one promise** + a title.
3. Write the **chorus first**. Chorus is simpler than verses. Title lives in the chorus.
4. Write verses that **earn** the chorus (new images, same promise).
5. Bridge turns **once**; chorus again.
6. Headings: plain `[Verse]` / `[Chorus]` unless a host kit is attached — then wrap with **that** host only.

## Must-not-break

- One promise. Do not stack three palettes.
- Chorus simpler than verses.
- Singable lines (~6–10 words; speech stress).
- Title in the chorus.
- Host tags only when that host kit is attached — never mix two hosts.

## Diegetic vs standalone

Default: a **complete song**.

If the scene only needs a snatch (radio in a bar, someone humming two lines): print the short excerpt **and** the full song underneath so the host (or the chapter) still has a finishable lyric.

## Unknown briefs

Nearest palette. Name the override in **one line**. Do not blend two palettes 50/50.

“Next summer’s top hit” → **Pop** (dance-pop / hit form). Not chart fortune-telling.
