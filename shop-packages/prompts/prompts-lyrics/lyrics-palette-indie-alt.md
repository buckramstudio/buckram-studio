# Palette — Indie / alt

Indie pop/rock. Specific diary images. Chorus is a punch, not a stadium sermon.

## Form

Verse-heavy. Chorus can be 2–4 lines that feel like a diary line you circled. Optional quiet bridge. No obligatory post-chorus chant.

## POV

First person. Specific “I.” You is one real person, not the crowd.

## Line density

Verses can run to ~10 words if the image is sharp. Chorus still shorter. Air between images.

## Rhyme

Slant OK in verses. Chorus: one clean landing. Do not couplet-machine the whole song.

## Imagery bank

Kitchen sink, bus window, thrift coat, named street, bad coffee, houseplant, voicemail, weather that sticks to a room.

## Chorus job

One diary punch that restates the promise without explaining it.

## Refuse

- Stadium gloss / gang vocals as default
- Generic heartbreak with no object
- EDM drop
- Three metaphors in one line

## Mini example (original)

Title: **The kettle clicks**

```
[Verse]
Your mug is in the sink
like you meant to come back
The kettle clicks and sits
I don't pour

[Chorus]
The kettle clicks
I let it
The kettle clicks
that's the whole visit
```
