# Song form

Job: pick a **known** section map for the palette. Do not invent a form for a hit brief.

## Light

Contract: section tags mark jobs, not decoration. A chorus that does verse-work is a failed form.

Must-not-break:
- Hit / pop briefs use V–C–V–C–B–C (or V–PC–C–V–PC–C–B–C)
- Blues uses AAB + refrain — not a pop pre-chorus stack
- Rap / hip-hop: dense verse + short hook
- Shanty: call–response, not a pop chorus
- EDM: sparse words; build / drop are jobs

## Normal

### Section jobs

| Section | Job |
|---------|-----|
| Intro | Optional. Mood or one image. Few or no words. |
| Verse | New evidence for the promise. Specific. Moves the little plot. |
| Pre-chorus | Only if the palette wants lift. Shorter. Points at the title without saying the whole hook. |
| Chorus | The promise. Simpler. Repeatable. Title lives here. |
| Post-chorus | Optional chant / tag. Even simpler than the chorus. |
| Bridge | **One** turn (new angle, reversal, or cost). Once. |
| Hook | Short catch — sometimes the chorus, sometimes a rap tag. |
| Outro | Last image or last title hit. Do not start a new story. |

### Default maps

| Palette cluster | Default map |
|-----------------|-------------|
| Pop, dance-pop, summer hit, disco, anthem, K-pop | Verse – Chorus – Verse – Chorus – Bridge – Chorus |
| Ballad, singer-songwriter, R&B slow jam | Verse – Chorus – Verse – Chorus – Bridge – Chorus (slower; longer lines still cut to ~10 words) |
| Blues (dark / electric / delta) | AAB verses; repeating refrain; no pop chorus padding |
| Hip-hop | Verse (dense) – Hook (short) – Verse – Hook – optional Bridge – Hook |
| Folk / Americana | Verses that witness; refrain that is **not** a pop chorus |
| Country | Verse plot; chorus = title-as-moral |
| EDM / dance, hyperpop drops | Sparse verse tags; Build / Drop as the event; lyrics get out of the way |
| Sea shanty | Call line, response line; work-song repeat |
| Musical theatre | Verse = book; chorus = want; bridge = decision |
| Jazz / torch | Verse–verse or verse–chorus; space for the hold; no EDM drop |

If the brief names a form (“12-bar”, “through-composed”, “one long verse”), obey that. Otherwise use the table.

## Hard

Do not add a pre-chorus, post-chorus, and breakdown to a blues or folk brief just because pop songs have them.

Do not write a new chorus lyric every time. Repeat it (host kits say how to paste the repeat).
