# Seedance 2.0 — staging & blocking

Where people/things sit in space and how they move through the set. Camera → `seedance-camera.md`. Continuity → `seedance-continuity-15s.md`.

**Target:** 2.0 only. State placement per shot; keep dense composition jargon Uncertain.

## Light

Job: make the set a navigable geography the model can keep — not a vibe caption.

Contract: positions, hands, props, entrances/exits, and depth are **stated**, not implied by plot.

Must-not-break:
- Count subjects and key props
- Prop ownership (which hand / who holds) through the clip
- Screen direction stays coherent unless you reverse on purpose
- Occlusion: what stays true while hidden
- Depth: foreground / mid / background jobs
- Per shot: who + where + what + how camera moves

### Placement language that steers

Treat **position / spatial change** as a first-class beat. Exact “left third” phrasing is craft (**Uncertain** as official enum).

| Pattern | Effect |
| --------- | -------- |
| Named station on set | Geography lock |
| Left / center / right third | Composition lock |
| Foreground X; subject mid; bg Y | Depth staging |
| Walks frame-left → frame-right beside landmark | Screen direction |
| Handedness + screen mapping at end state | Prop continuity |

### Blocking beats (physical order)

1. Approach / path
2. Contact (hand, tray, foot, prop)
3. Transfer of force / ownership change
4. Recovery / settle

### Eyelines & attention

| Write | Not |
|-------|-----|
| Eyes move to the door; gaze fixed on the other man | She becomes afraid |
| Looks down at impact, then to sketchbook | Looks surprised |

### Depth & layers

| Layer | Typical job |
|-------|-------------|
| Foreground | Occluder, reveal prop, parallax |
| Mid-ground | Primary blocking / dialogue |
| Background | Atmosphere life that must **not** steal identity (“stationary”, “mid-background”) |

### Entrances / exits

- Name **edge** and **limb** used.
- State whether camera follows out or **stays**.
- After exit: what remains in frame.

### Occlusion (hidden continuity)

- How long fully hidden
- Same identity, clothing, prop, direction, speed on re-exit
- “No person/prop on both sides at once”
- Landmark that stays fixed

### Environment clauses that matter for stage

| Include | Why |
|---------|-----|
| Time of day / weather that affects visibility | Silhouette, reflections |
| Fixed props and rest positions | Prevent teleport |
| Layout / markings / bench orientation stable | Geography lock |
| Background state (lamp on; cooler closed) | Starting state |

**Note:** Seedance **2.5** clay-render / white-box spatial referencing is **not** documented as a 2.0 launch feature here — do not import that recipe from the 2.5 set. For extension repair, converting a clip to a white 3D model to stabilize **extension** quality; that is an extend/repair tip, not clay R2V staging.

## Hard

**Handedness ledger** — name hand at start, after each action, at end.

**No teleport rule** — objects don’t reset when off-screen unless you say they do.

**Fluids / cloth / particles** — force direction + final settled state.

**Dialogue blocking** — mouth moves only during own lines.

| Failure | Fix |
|---------|-----|
| Extra limbs / duplicate props | Count + “no duplicated X”; ownership line |
| Hands swap randomly | Repeat hand ownership each Shot N |
| Background steals scene | “mid-background”, “stationary” |
| Jump after occlusion | Repeat invariant list on emerge |

**Uncertain:** multi-person eyeline obedience — keep to 2–4 primary bodies.
