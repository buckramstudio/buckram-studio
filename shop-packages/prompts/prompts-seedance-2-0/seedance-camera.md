# Seedance 2.0 — camera vocabulary

Drive **how we see** the stage. Pair with `seedance-staging.md`. Continuity → `seedance-continuity-15s.md`.

**Target:** 2.0 only. Prefer standard shot terms; mark niche terms Uncertain.

## Light

Job: one clear camera plan the model can hold for the whole clip (or per Shot N).

Contract: **name the move**; say who it follows; say when it starts and stops (relative words OK).

Must-not-break:
- Camera clause ≠ subject-action clause
- One dominant camera idea unless Shot N changes it on purpose
- **One move per shot** — don’t stack push + pan + tilt + orbit in the same beat
- Vague “cinematic / dynamic” does not steer
- Niche term → also describe observable picture change

## Normal

### Shot size

| Term | Use for |
| ------ | --------- |
| Wide / full / 全景 | Full body + environment |
| Medium / 中景 | Waist-up / interaction distance |
| Close-up / 特写 | Face, hands, product detail |
| Extreme wide / extreme close-up | Scale or micro detail |

Also useful: medium-wide, MCU — treat as size-ladder extensions (**Uncertain** as official synonym list).

### Angle / viewpoint

| Term | Effect |
| ------ | -------- |
| Eye-level | Neutral |
| Low / high / overhead | Power / map / vulnerability |
| Dutch angle | Unease |
| FPV / micro-FPV | Body-mounted path |

### Movement keywords

| Keyword | What happens |
| --------- | -------------- |
| Slow push-in / 缓慢推镜 | Toward subject |
| Pull-back / 拉远 | Away from subject |
| Steady lateral track / 平稳横移 | Sideways; state left↔right |
| Follow / 跟拍 | Trails subject; state height |
| Pan / 横摇 | Yaw left/right |
| Static / locked-off / 固定镜头 | No camera move |
| Cut to / 镜头切至… | Planned join |
| Arc / orbit / crane / whip-pan / dolly zoom | Specialist moves |

Formula for uncommon terms:

`[term] + [target] + [how picture changes] + [fg/bg] + [direction or speed]`

### Cuts vs continuous

| Mode | Prompt habit | Maker note |
|------|----------------|------------|
| **Continuous / locked path** | “固定机位” or one named move; avoid cut soup |
| **Planned cuts** | `镜头切至…`; keep axis/screen direction |
| **Montage density** | Explicitly ask for varied angles/inserts |

### Screen-space framing

| Specify | Example |
|---------|---------|
| Subject’s third | “keep messenger in left third” |
| Height | “chest height behind”, “door-height track” |
| Axis lock | “never cross the aisle axis” |
| Move trigger | “camera does not pan until the door opens” |
| Settle | “ends mid-stride at frame right” |

### Prefer / avoid

| Prefer | Avoid |
|--------|-------|
| 全景缓慢推近 → 中景 | zoom in cinematically |
| 平稳横移, subject centered | dynamic camera |
| 固定镜头; all motion from walk | camera somehow follows somehow |
| one named move this shot | push + pan + tilt + orbit together |

### Duration vs camera complexity (field; host-dependent)

| Duration (typical 2.0 host) | Camera budget |
|-----------------------------|---------------|
| 4–5s | One move or locked; one beat |
| ~8s | One arc |
| ~15s | 2–3 Shot-N camera beats |

## Hard

**Name camera first** when the shot must not become “subject wiggles because frame was static.”

**Separate axes:**

```
Camera: 缓慢推镜 from medium to close-up; subject stays centered.
Subject: three controlled kettlebell swings, chest-height apex, steady rhythm.
```

**Multi-subject frames:** say who the move is built around.

| Failure | Fix |
|---------|-----|
| Drift / float | Lead with concrete move + locked subject position |
| Camera + subject mush | Split clauses; one move |
| Cut chaos | Fewer joins; keep axis |
| Fancy term ignored | Term + visible change |
| Stacked moves | Drop to one named move |

**Uncertain:** synonym coverage for niche English terms (truck, dolly-zoom, bullet time) on 2.0 — prefer the CN/EN pairs above.
