# ElevenLabs Music

UI prompt plus lyrics, or composition-plan text blocks. Write the song first; this kit only formats ElevenLabs paste. No SDK samples.

Installing this craft kit adds focused guidance into your project Library. It steers outlining, drafting, or revision toward the topics below — exact Agent use depends on how the pack is wired after install.

**What it tends to cover**
- `prompts-elevenlabs-music.md`
- `elevenlabs-lyrics-tags.md`
- `elevenlabs-style-prompt.md`
- `elevenlabs-paste-templates.md`
- `elevenlabs-failure-modes.md`

If **Song lyrics** is also installed, write the song there first. Do not mix this kit with Suno, Udio, or Mureka tags in one paste.

**Tags:** prompts, music, elevenlabs

Open **About this pack** any time before or after install. After install, use the Files list to read notes and turn off pieces you do not want attached.
