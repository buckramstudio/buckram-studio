# Mureka — style prompt

Separate field from lyrics. Genre, mood, vocal, pace.

```
r&b, slow, passionate, male vocal
```

```
dark electric blues, spare, understated, male vocal
```

```
dance-pop, summer, bright, female vocal
```

## Do

- Short comma tags
- Vocal gender / tone here
- Match the lyric’s palette (don’t prompt EDM under a blues lyric)

## Don’t

- Structure tags in the prompt
- Paste the full lyric into the prompt
- A paragraph of studio theory
