# Mureka — failure modes

Fix the failing axis only.

## Light

Must-not-break:
- Locked tags only
- Short lines
- Chorus simpler than verses
- Style in the prompt field
- One host kit

## Normal

| Don’t | Do |
|-------|-----|
| 14-word prose lines | 6–10 words |
| Dense chorus | Simpler than verses |
| `[Drop]`, `[Announcer]`, `[Final Chorus]` | Locked list |
| `[Verse: whispered, acoustic only]` | `[Verse]` + whisper in the prompt |
| `{guitar solo}` | `[Break]` or instrumental `[Intro]` / shorter verse |
| Style tags inside lyrics | Prompt field |
| Mixing hosts | This kit only |

## Hard

If structure wanders, restore Verse–Chorus–Verse–Chorus–Bridge–Chorus–Outro before adding `[Pre-Chorus]` and `[Break]`.
