# Mureka — lyrics tags

Locked list. Do not invent extras.

`[Intro]`, `[Verse]` / `[Verse 1]`, `[Pre-Chorus]`, `[Chorus]`, `[Bridge]`, `[Break]`, `[Outro]`

One tag per line, then the lines for that section. Number verses when needed: `[Verse 1]`, `[Verse 2]`.

## Default map

Verse → Chorus → Verse → Chorus → Bridge → Chorus → Outro.

Add `[Intro]` or `[Break]` only when the brief needs them. `[Pre-Chorus]` only if the song actually lifts.

## Lines

~6–10 words. Chorus simpler than verses. Repeat the chorus by pasting the words again — a tag alone does not re-sing.

## Don’t

- Suno parameterized `[Verse: whispered vocals, …]` as default
- Udio `[Pre-chorus]` / `[Drop]` / `[Announcer]`
- ElevenLabs `{guitar solo}` / `(ooh)` as a system (plain lyric is fine)
- Style words as tags (`[Sad]`, `[120 BPM]`)
