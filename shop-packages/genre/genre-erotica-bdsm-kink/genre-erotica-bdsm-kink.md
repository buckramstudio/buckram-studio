# BDSM / kink erotica (incl. D/s)

Engine: **negotiated power exchange as the story’s trust ladder** — dominance/submission, bondage, discipline, sadomasochism, or other kink as the sexual journey’s spine. Market often files under erotica *or* erotic romance; structure (HEA?) decides.

## Light

Job: make negotiated power exchange the trust ladder — rules the characters know, desire that chooses.

Contract: consent frameworks on the page; submission as agency; each major scene changes the dynamic; heat serves the exchange.

Must-not-break:
- Power has rules the characters know (even if rules evolve)
- Negotiation, safewords/signals, aftercare are plot tools — not optional garnish
- Consent is ongoing; silence ≠ yes under intensity
- Abuse labeled “BDSM” without negotiation frame fails the lane
- CNC needs diegetic prior agreement — don’t blur with noncon marketing
- HEA only if erotic-romance structure; else position as erotica

## Normal

**Genre shape**
- D/s relationship development is a classic erotica skeleton: negotiations, tests, earned trust, possible collapse/rebuild
- Pairing (M/F, M/M, F/F, multi) does not change the consent architecture requirement
- If HEA/HFN + love story primary with kink load-bearing → erotic romance; if sexual dynamic *is* the spine and ending open → erotica

**Consent frameworks as craft**

| Framework | Craft use on the page |
|-----------|------------------------|
| **SSC** (Safe, Sane, Consensual) | Baseline language readers recognize; good for negotiation/teaching arcs |
| **RACK** (Risk-Aware Consensual Kink) | Characters acknowledge inherent risk; informed choice > slogan “safe” |
| **PRICK** (and kin) | Personal responsibility rhetoric — useful when characters argue ethics of edge play |

Show, don’t sermon:
- Negotiation is story (desire lists, hard/soft limits, what “no” costs socially)
- Safewords / non-verbal signals are plot tools — ignoring them is a consent-violation beat, not spice
- Aftercare is relationship data: specific care vs performative “good Dom” speech

**Power exchange without abuse-as-kink**
- Kink dominant consults negotiated desire; abuser consults only their own — reader must tell which story they’re in
- Training/punishment/pet play aesthetics without consent context are diction traps  — earn through negotiation
- Research practical safety only as far as realism serves — fiction craft, not a how-to manual

**Structures that fit**
1. Initiation / mentor dynamic (adult–adult) → claimed role or exit
2. Established couple opens a kink door → relationship renegotiation
3. Club/community setting → public vs private power, reputation stakes
4. 24/7 protocol fantasy → logistics, burnout, renegotiation mid-book

| Failure | Fix |
|---------|-----|
| Abuse labeled “BDSM” | Negotiation, safewords, aftercare — or recategorize dark with warnings |
| Contract speech mid-act | Embodied consent + earlier negotiation |
| Dom perfection / sub pure object | Competence + vulnerability both sides |
| Edge play as decoration | Cost, risk awareness, aftermath |
| HEA readers in open-ended D/s tragedy | Position as erotica or earn HFN/HEA |

## Hard

**Framework debates (decision-changing)**
- SSC vs RACK changes character ethics arguments and edge-play aftermath — pick which vocabulary your cast believes
- Dark erotica coercion aesthetics ≠ kink — different tags, different trust with the reader 
- Workplace / age-gap power without formal kink negotiation → adjacent files, not automatic BDSM shelf

**When to break “safeword always works”**
- If safeword is ignored, that is harm — consequence and possibly retag toward dark/harm narrative; do not treat as default spice
- Incomplete aftercare can be a thematic choice with cost — not “skipping craft” unnoticed
