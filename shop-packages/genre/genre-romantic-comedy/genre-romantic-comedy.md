# Romantic comedy (novel)

Engine: meet-cute → comic obstacles → earned HEA — humor is load-bearing, not garnish; the laugh engine and the romance engine must share the same plot spine.

## Light

Job: make the comic premise and the courtship the same machine — jokes that don’t serve Want fail.

Contract: warmth + wit; mean-spirited pile-on without affection usually breaks the shelf. Parent HEA: . Page comic craft: .

Must-not-break:
- One comic premise sentence a stranger can repeat
- Dual GMC still required — jokes don’t replace Want
- Comic Black Moment — funny setup turns costly; relationship genuinely at risk
- HEA that keeps the joke’s world — no sudden prestige-gloomy abandon
- Misunderstandings need near-miss logic, not idiot plotting
- Banter that changes — speech marks intimacy gradient

## Normal

**Genre shape**

- Novel Rom-com inherits film grammar (meet-cute, comic misunderstanding, public humiliation, grand gesture) but needs chapter-scale interiority
- Overlaps chick-lit / CR / WF-comedy — position by **promise** (couple HEA vs career-friendship ensemble)
- Satire can sit under rom-com if the couple still carries the ending

**Obligatory pressures**
- Meet-cute or meet-awkward that plants comic premise + attraction
- Incompatible life-plans / identities generating recurring set-pieces
- Public embarrassment / status risk
- Banter intimacy gradient
- Comic Black Moment
- Recognition / grand gesture that solves the *right* problem (Essence, not only MacGuffin)
- HEA that keeps tonal contract

**Working checklist**

- Supporting cast as pressure, not only sitcom cameos
- Sex/heat optional; if steamy, keep comic timing 
- Farce acceleration when escalating → 

| Failure | Fix |
|---------|-----|
| Quips, no courtship | Restore Want/Need + obstacles |
| Punching down as only joke | Warmth + punch up |
| Third-act seriousness whiplash | Earn tonal shift or keep comic contract |
| Handwave HEA | Resolve established incompatibilities |

## Hard

**Promise positioning**

- Couple HEA primary → rom-com / CR
- Career-friendship ensemble primary with optional romance → chick-lit / WF-comedy lean
- Satire under rom-com only if couple landing still load-bearing 

**Timing ↔ romance synthesis**

- End-stress / physicalized punchlines after page- or chapter-turns
- After devastating beat: restraint → later laugh lands harder (don’t cheat with instant gag)

**When to break pure warmth**
- Bittersweet edges OK if the joke’s world still holds
- Prestige-gloomy third act without setup = contract break
