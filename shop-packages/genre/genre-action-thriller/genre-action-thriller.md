# Action thriller

Engine: set-piece survival under a clock; chase geography and physical competence drive the page; emotional stakes hitch to each ordeal so spectacle isn’t empty.

## Light

Job: deliver thriller apprehension primarily through kinetic threat — pursuit, combat, escape, race.

Contract: hard professional or ordinary person forced into competence under fire; spectacle must change relationships or goal, not only volume.

Must-not-break:
- Clear geography each set-piece (bodies, exits, props, sightlines)
- Escalate constraints (injury, ammo, hostages, public space) not only bigger explosions
- Competence fantasy needs costs: mistakes, collateral, moral residue
- Quiet aftermath makes the next hit land
- Causal chain between set-pieces

## Normal

**Genre shape**

- Thriller emotion (apprehension, anticipation) via kinetic threat
- Overlaps adventure, spy, military, crime — label follows which engine bills first
- Short chapters / cliffhangers still need recovery + plan beats — pure chase fatigue flattens

**Working checklist**

- Trackable space per ordeal 
- Resource accounting (ammo, injury, time, public exposure)
- Betrayal / intel flip mid-chase
- Physical cost that sticks into the next scene
- Climactic confrontation in constricted or spectacular space

**Obligatory pressures**
- Clock + pursuit established early
- Set-piece geography the reader can track
- Capability test — skill or improvisation under fire
- Betrayal / intel flip
- Physical cost that persists
- Climactic confrontation with changed stakes

| Failure | Fix |
|---------|-----|
| Interchangeable set-pieces | Causal chain + rising constraints |
| Invincible hero | Resource and injury accounting |
| Unvisualizable fight | Geography + sightlines first |
| Action that changes nothing | Each ordeal flips goal/relationship |

## Hard

**Engine billing vs siblings**

- If puzzle/fair play bills first → / crime siblings
- If tradecraft/institutions bill first → 
- If exploration/quest wonder bills first → 
- Keep parent thriller info-privilege tools when dread > choreography 

**Spectacle ↔ cost synthesis**

- Bigger explosions without constraint escalation = flat intensity 
- Aftermath stillness is structural, not padding 
- Moral residue after competence fantasy prevents video-game invulnerability

**When to break chase pace**
- Plan/recovery beats can be longer if the clock remains audible
- Public-space constraints can replace injury when body-count fatigue sets in
