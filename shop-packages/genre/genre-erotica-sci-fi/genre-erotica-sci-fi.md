# Sci-fi erotica

Engine: **a novum that changes bodies, reproduction, privacy, or sexual culture** — tech, aliens, space logistics — with sexual journey as spine. If the love story + HEA dominates, you’re in SF romance; if the case/novum dominates without sex-spine, plain SF.

## Light

Job: make the novum change intimacy logistics — speculative element is load-bearing for sex, not a viewport sticker.

Contract: consistent biology/tech rules; culture shock as erotic fuel; strip novum and sex scenes should break.

Must-not-break:
- Speculative element changes intimacy logistics
- Consistent biology/tech rules — side effects matter
- Culture shock / consent-norm translation dramatized
- Adult characters only — no child-coded androids
- Sense of future/other — not contemporary bedroom with stickers
- HEA bait vs open erotica — honest positioning ( vs erotica)

## Normal

**Genre shape**
- Novum examples that earn the shelf: alien biology, neural links, body-mod, fertility tech, surveillance states, generation-ship norms, AI/embodied companions (**adult** characters)
- **Erotica:** sexual adaptation/discovery is the plot
- **Erotic SF romance:** HEA + sex load-bearing under speculative constraint
- Hard SF readers may bounce off heat-first; heat readers bounce off lecture — balance for lane

**Reader promises**
1. Novum changes intimacy logistics
2. Consistent biology/tech rules
3. Culture shock as erotic fuel
4. Sense of future/other

**Consent / power craft**
- Translation devices / telepathy: mind-reading that removes privacy needs negotiation
- Species/tech power: ability to refuse visible or dark-framed
- AI/robot partners: agency and personhood are theme — avoid “appliance” without argument
- Military/rank aboard ship ≈ workplace power lessons

**Structures that fit**
- First contact courtship protocols
- Body-mod recovery + desire reclaiming
- Arranged diplomatic bonding with real chemistry risk
- Closed-ship pressure cooker

| Failure | Fix |
|---------|-----|
| Tech brochure mid-climax | Cost/sensation through POV |
| Human porn + green skin | Alter sensation, taboo, or consequence |
| HEA bait / open erotica swap | Honest BISAC and blurbs |
| Utopian consent with no friction | Cultural mismatch as plot |
| Predator alien unmarked | Agency + notes; see monster file |

## Hard

**SF vs SF romance vs erotica**
- Case/novum-first without sex-spine → plain SF; love+HEA primary → SF romance; sexual adaptation primary → SF erotica
- Earth-supernatural heat usually routes to paranormal, not SF 

**When to break “hard consistency”**
- Soft SF intimacy can use one clear constraint (surveillance, fertility law, closed ship) without full physics — constraint must still bite
