# Gaslamp fantasy

Engine: Victorian / Edwardian (or analogous) aesthetic + unexplained supernatural — manners and lamp-lit society pressure a magic/uncanny plot.

## Light

Job: keep magic/weird load-bearing; machines may decorate but must not be the argument.

Contract: Neo-Victorian (or analogue) manners + occult/supernatural pressure; if removing machines kills the plot → steampunk; if removing the uncanny kills it → gaslamp.

Must-not-break:
- Uncanny forces choice under etiquette/reputation
- Consistency for the weird (even soft magic)
- Cost of knowing — can’t fully return to drawing-room innocence
- Period constraint remains at resolution
- Don’t SEO-label aether-as-magic “steampunk”
- Pin primary shelf for comps (fantasy vs historical vs romance hybrid)

## Normal

**Steampunk vs gaslamp**

| | Steampunk | Gaslamp fantasy |
|--|-----------|-----------------|
| Load-bearing | Steam/retro tech social argument | Magic / supernatural |
| Explanation | Mechanistic / pseudoscience | Often unexplained or occult |
| Failure mode | Costume gears | Fog + etiquette without uncanny stakes |

**Furniture / pressures**
- Common furniture: séances, vampires, fae courts in London, sorcerous aristocracy, occult societies
- Masquerade or occult reveal under manners
- Etiquette as obstacle — reputation, chaperonage, class vs supernatural need
- Bargain / contamination with the weird
- Society set-piece (ball, séance, club, exhibition) where public face cracks
- Research enough period texture for illusion without museum voice
- If romance co-billed, keep HEA/HFN 
- Gothic house/ancestral sin → lean when excavation dominates

| Failure | Fix |
|---------|-----|
| Steampunk cosplay + unexplained magic, no tech argument | Pick gaslamp or add real tech hypothesis |
| Manners tourism; supernatural never forces choice | Tie weird to Want/reputation cost |
| Modern therapy-speak in period mouths | Period-true diction + subtext |
| Empire aesthetics with unpaid cost | Show who pays |

## Hard

**Term / shelf edges**
- “Gaslamp fantasy” popularized to name Neo-Victorian fantasy that is **not** steampunk’s engineering hypothesis (wiki + steampunk contrast notes)
- Overlaps historical fantasy, gothic, and romantasy — primary promise decides comps and obligatory moments
- Soft magic still needs fair-play consistency when magic solves climax problems ( / Sanderson First Law pressure via parent)

**Cross-lane collisions**
- PNR: supernatural rules complicate courtship — HEA still owed if romance-primary
- Gothic: excavation/atmosphere may dominate without “gaslamp” manners engine — don’t force both labels
- Steampunk hybrid: both tech argument and uncanny must be load-bearing, or one is costume

**When to break period fidelity**
- Analogue societies (secondary-world “gaslight age”) OK if etiquette + uncanny pressure remain
- Magic that erases class overnight needs drama and cost — utopia wipe fails the manners engine
