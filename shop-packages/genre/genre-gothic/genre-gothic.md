# Gothic fiction

Engine: **atmosphere + buried secret + uncanny**. Unsettles; does not require visceral scare. Setting is not backdrop — it is pressure.

## Light

Job: excavate what the place/lineage buried — dread and ambiguity over jump-scare.

Contract: haunted / decaying / institutionally oppressive setting with history; secrets threaten the present; uncanny familiarity.

Must-not-break:
- Atmosphere over action — unease before threat
- Setting *is* the story pressure, not wallpaper
- Ambiguity central — “is it real?” often load-bearing
- Past must threaten present (not museum history)
- Outsider (or trapped insider) discovers with the reader
- Not costume horror alone — psychology and excavation matter

## Normal

**Gothic vs horror**

| Element | Gothic | Horror |
|---------|--------|--------|
| Primary emotion | Dread, unease | Fear, terror |
| Pacing | Slow build, lingering | Can be fast / shock |
| Violence | Implied or restrained | Often explicit |
| Ambiguity | Central — is it real? | Often resolved — threat is real |
| Focus | Psychology, atmosphere, excavation | Threat, survival |
| Setting | Setting *is* the story | Setting is where story happens |
| Core question | What is wrong with this place/lineage? | How do we survive this? |

Blend common (*Hill House*); know primary mode for reader promise. Radcliffe lineage (also in ): **terror** (anticipation) > **horror** (confrontation) > **revulsion** — gothic lives longest in terror + ambiguity. Can be zero-scare (*Jane Eyre*, *Rebecca*).

**DNA / setting as character**
- Haunted / decaying / institutionally oppressive space with history
- Secrets and family (or institutional) trauma — plot as excavation
- Uncanny: familiar made wrong; unreliable perception (grief, illness, sleeplessness)
- Architecture as metaphor: locked rooms = secrets; labyrinth = entrapment; tower = isolation
- House resists discovery: keys vanish, evidence destroyed, knowers die/disappear
- Restrict freedom: geographic, social, or psychological trap

**Protagonist + excavation engine**
- Classic: outsider enters a space that already knows more than they do (new wife / governess / heir / investigator)
- Perceptive but doubted — observations correct, environment gaslights
- Layer revelations: each fragment raises questions; doubling/mirrors (current vs first wife; portraits as parallels)
- Pathetic fallacy expected — use deliberately 

**Working checklist**
- Promise unease in the space early
- Hold ambiguity as long as the genre promise allows
- Weather/world mirrors inner drama without drowning the human story
- Contemporary setting: diegetic blockers for phones/police/search if isolation is required

| Failure | Fix |
|---------|-----|
| All atmosphere, no goal/obstacles | Give Want + excavation stakes |
| Explain mystery too early | Layer; protect ambiguity |
| Setting overwhelms human grief/guilt | Keep cruelty/guilt load-bearing |
| Costume horror only | Excavate lineage/secret |

## Hard

**Subgenre dials (retag when primary)**
- **Southern gothic** — regional history of harm; grotesque social truth
- **Domestic gothic** — marriage/home as confinement; may be zero supernatural
- **Gothic romance** — love interest = possible salvation *or* destruction (*Rebecca*); not a separate organized file — stack romance contract if HEA required
- **Contemporary / new gothic** — smart homes, compounds, online haunting; same principles, new walls
- If community ritual + folk belief lead → ; if visceral transformation leads → 

**Prose levers**
- Trap/anxiety → short fragments; oppressive mood → long coiling sentences
- Atmospheric ≠ purple (“house exhaled a draft” > “infinite malevolent miasma”)
- Early “ghost is real” can flip book into horror mode — choose deliberately

**When to break slow-build**
- Shock OK if aftermath returns to excavation and ambiguity cost
- If survival threat dominates every beat → label/primary
