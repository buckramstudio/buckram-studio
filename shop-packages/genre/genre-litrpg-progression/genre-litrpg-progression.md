# LitRPG & progression fantasy

Engine: measurable advancement as plot — power, skills, and understanding rise in ways the reader can track; in LitRPG the visible system UI is part of the reading experience.

## Light

Job: design the system before chapter one so level-ups change tactics *and* self — not spreadsheet wallpaper.

Contract: LitRPG shows stats/UI; progression fantasy may hide UI but still measures power (`Cradle`-style).

Must-not-break:
- System-first design — bolt-on stats after drafting → hollow fiction
- Power curve ∥ emotional curve
- New power unlocks **new problems**
- Stat boxes pass a three-function test (info / tension / understanding) or cut
- Constraints triad: capability gates resource costs threat adaptation
- Broken rules for author convenience = trust nuke

## Normal

**Definitions**

- **LitRPG:** RPG conventions inside a novel; **visible stats** significant; protagonist usually conscious of progressing
- Coined ~2013 (Russian EKSMO / Mahanenko–Malkin–Bobl); precursors: game-inside stories, VRMMORPG, East Asian LN/isekai
- **GameLit:** game-world without mandatory leveling crunch
- **Progression fantasy:** measurable level-up through world’s power system — need not show game UI

**System-first design**

Before ch.1: how XP is earned; which stats; hard limits; edge cases; hidden mechanics; exploit potential; **3–5 core rules** visible through action; thematic resonance; system bible

**Stat boxes & progression pacing**

- Three-function test; keep blocks lean; surround UI with emotion
- Plateaus, failed grinds, earned breakthroughs > administrative level-ups
- Series: reveal system layers instead of pure number inflation
- Early UI may be unreliable narrator of deeper truth — plan full reveal arc

**Obligatory moments**
- System contact; build choice that hurts; exploit/insight beat; milestone level-up; party/faction system conflict; rule fracture

| Failure | Fix |
|---------|-----|
| Ch.1 system lecture; spreadsheet chapters | Teach under pressure; cut unused UI |
| Progression mistaken for character arc | Power curve ∥ person-change |
| Unearned specialness page one | Earn via cost/choice |
| Flat power: bigger numbers, same problems | New problems per power |
| Broken rules for convenience | System bible; no author cheats |

## Hard

**UI as unreliable narrator**

- Plan admin/anomaly/moral no-win the UI can’t score before publishing book one
- Optimal game choice vs moral/relational/self choice is the best engine

**When to break visible stats**
- Migrate toward progression fantasy (no UI) if audio/pace demands — keep measurable advancement promise
- GameLit without leveling: different contract — don’t bait LitRPG readers with cover System language then withhold crunch
