# Science fiction

Engine: the **novum** — the new thing / “what if?”

## Light

Job: make one central strange newness create conflict and rethink Tuesday — not chrome costume.

Contract: cognitive estrangement — alternative reality that pressures jobs, law, love, lunch; science/speculation frames the hypothesis.

Must-not-break:
- One central novum (or tightly linked cluster) — don’t overstuff
- Extrapolate: if X exists, what does Tuesday look like?
- Science/speculation **creates** conflict, not only decorates setting
- Reveal world through character encountering it — avoid tour-guide dump
- Pick hardness/opera/punk shelf honestly for comps
- Empty novelty as costume fails the estrangement test (Suvin craft warning)

## Normal

**Novum + cognitive estrangement (Suvin)**
- **Novum:** strange newness that frames the work’s hypothesis (tech, discovery, society, timeline…)
- **Cognitive estrangement:** alternative reality presented so readers rethink the status quo
- Commercial SF that uses novelty only as costume isn’t “SF at heart” by this critical lens — still useful as craft warning

**Hard vs soft vs opera**
- **Hard:** procedural rigor with known/extrapolated science — 
- **Soft:** social sciences / people / mythic feel; physics may be handwaved — 
- **Space opera:** epic scale adventure; enabling tech often assumed — 
- Later real-world discovery needn’t strip a “hard” label if the story reasoned honestly from its era

**Subtype pointers (engines)**
- Military / time travel / first contact / generation ship / near-future / utopia / cyberpunk / biopunk / solarpunk / steampunk / dystopian / AH / climate — see dedicated notes; hub 

**Working checklist**
- Research feeds: NASA, arXiv, worldbuilding.SE — 
- Sanderson soft↔hard magic analogy useful for fair play 
- World depth process: 

| Failure | Fix |
|---------|-----|
| Kitchen-sink novums | One hypothesis, deep Tuesday |
| Gadget wallpaper | Make tech create the conflict |
| Infodump lecture | Character problem-solving reveal |
| Wrong shelf comps | Hard vs opera vs punk vs dystopia |

## Hard

**Critical vs commercial lens**
- Suvin’s estrangement is a craft diagnostic, not a gatekeeping purity test — use it to catch empty chrome
- Soft sociological classics can still be rigorous about anthropology/linguistics
- Hybrids common: opera scale + rigor; punk street + novum

**Cross-lane synthesis**
- Social novum of oppression → 
- High tech / low life → 
- Portal threshold fantasy-first → (SF wormholes still need novum discipline)
- Near-now tech thriller without estranged Tuesday → 

**When to break “one novum”**
- Linked cluster OK if one hypothesis spine remains
- Series may add systems — interconnect thematically; don’t silent-contradict prior rules
