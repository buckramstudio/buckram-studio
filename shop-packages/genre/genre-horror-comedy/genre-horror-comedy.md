# Horror-comedy

Engine: tension → release toggles between dread and laugh. Both engines must work — comedy in a monster costume is not enough.

## Light

Job: write a scary horror *and* a funny comedy; neglect either and the hybrid collapses.

Contract: balance need not be 50/50 — lean scare (*Scream*) or lean laugh (*Ghostbusters*) but name the lean; shared structure is setup/pressure then punchline *or* scare.

Must-not-break:
- Fear first — tension primes the laugh
- Know the horror rules of your chosen subgenre before subverting them
- Characters cared about — dark jokes need stakes respect
- Don’t undercut every dread beat with a wink (no residual fear)
- Don’t punch victims/trauma for cheap laughs without care

## Normal

**Genre contract**

- Shared release muscles: pressure then comic or scare payoff
- Characters must be cared about for dark-topic jokes to land

**Three craft moves**

1. **Focus on fear first** — start from a real scare (physical, metaphysical, emotional)
2. **Know the horror rules** — list tropes; play with or against them for comedy (garlic chips; narcissist werewolf)
3. **Mundane into madness** — cultists do laundry; ghosts wait around — bathos as release

**Mix patterns**

- Mood dissonance: funny characters, horror played straight
- Trope parody: acknowledge then subvert (optional fourth wall)
- Straight-man voice saying “that’s ridiculous” for the reader
- Timing: joke after scare, or fake-out where expected joke is a scare
- Splatstick: excess violence as dark choreography — commit to cartoon physics or it reads as cruelty

| Failure | Fix |
|---------|-----|
| Gags so dense scares never land | Protect dread residual |
| Wink after every beat | Let some terror stand |
| Punching victims | Aim jokes at tropes/power, not trauma |
| No horror rules established | List tropes before subversion |
