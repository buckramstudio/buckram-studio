# Conspiracy thriller

Engine: a hidden system (state, corp, cult, cabal) manipulates the visible world; protagonist must prove, survive, or escape the web; paranoia is a feature when earned by pattern, a bug when unmotivated.

## Light

Job: turn one wrong thread into a visible system — appearances vs reality under thriller pressure.

Contract: protagonist (often journalist/amateur) pulls a small thread that leads “all the way to the top”; endings may stay pessimistic if seeded.

Must-not-break:
- Seed pattern early; coincidences later re-read as design
- Conspiracy has goal, logistics, and human faces — not omniscient fog
- Paranoia tax: allies may be plants; prove trust with tests
- Climax answers how the system works **and** what the protagonist can still change
- Fairness when puzzle-heavy — reader can connect some dots

## Normal

**Genre shape**

- Rumors, propaganda, counter-propaganda tangle coincidence and design
- Adjacent: spy/espionage when tradecraft & institutions primary; medical/legal/techno when domain-specific
- Classic moves: whistleblower, framed innocent, peeling layers, “nobody believes you” middle
- Scale: small-town cover-up → transnational apparatus — pick one dominant scale and escalate inside it

**Working checklist**

- Information architecture: documents, leaks, surveillance, memory holes
- Institutional face named (agency, corp, cabal)
- Capture / smear / near-erase attempt midbook
- Prove / escape / burn-it-down climax with incomplete safety

**Obligatory pressures**
- Ordinary world cracked by one wrong document/death/pattern
- Paranoia escalation — safe contacts compromised
- Evidence trail partly assemblable by reader
- Institutional face of the conspiracy
- Capture / smear / near-erase
- Incomplete-safety climax

| Failure | Fix |
|---------|-----|
| Infinite regress cabal | Land the system’s goal and cost |
| Protagonist only chased | Investigation agency required |
| Hate-myth recycling | Ethical landmine — invent or research carefully |
| Omniscient villains | Give the system error and logistics |

## Hard

**Spy vs conspiracy dial**

- Tradecraft + institutional operators as primary pleasure → 
- Amateur/journalist peeling a hidden design → stay here
- Domain engines (medical/legal/techno) can host conspiracy — keep domain clock load-bearing

**Paranoia as craft, not vibe**

- Pattern evidence must precede paranoia tax or reader feels gaslit by the author
- Pessimistic ending (system persists) is a valid contract if seeded — don’t bait reform triumph then shrug

**When to break scale**
- Escalating inside one scale beats teleporting from PTA cover-up to Illuminati without ladder rungs
- Borrow mystery clue economy when the book sells “figure it out”
