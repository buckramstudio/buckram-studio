# Dark fantasy

Engine: **horror-tinged fantastic** — dread, the uncanny, or aesthetic terror woven into fantasy formulae; darkness as atmosphere and theme, not only body count.

## Light

Job: make horror *affect* load-bearing inside a fantasy (or fantastic-horror) contract.

Contract: supernatural weight and dread logic; not automatic grimdark (rotten-systems morality) and not splatter-only “dark” pigment.

Must-not-break:
- Wrongness / contamination beats, not gloomy wallpaper
- Magic or mythic logic still plays fair enough for climax
- Contrast (beauty, humor, tenderness) so bleakness doesn’t numb
- Pin shelf: fantasy-with-dread vs horror-with-fantastic — comps must match
- Dawn that doesn’t fully cleanse — persistence of the dark
- Sexual violence / gore as wallpaper = known sin

## Normal

**Definitions (keep the split clear)**
- Stableford: incorporate **horror elements** into standard fantasy formulae
- Setting test: supernatural horror in primary world ≈ contemporary fantasy; in secondary worlds ≈ dark fantasy
- Term is ambiguous in trade — pin *your* contract for the reader early

**Dark fantasy ≠ grimdark (necessarily)**

| | Dark fantasy | Grimdark |
|--|--------------|----------|
| Core | Horror/uncanny affect inside fantasy | Agency under rotten systems; moral compromise engine |
| May include | Sympathetic vampires, weird secondary worlds, aesthetic terror | Institutional cruelty, pyrrhic politics |
| Failure mode | Gloomy wallpaper without dread logic | Cruelty mistaken for depth |

**Conventions / obligatory pressures**
- Brooding tone; monster POV or sympathetic supernatural vs victim-survival
- Wrongness beat → bargain/contamination → safe space violated → sympathy trap → aesthetic peak → price of knowing → dawn that doesn’t cleanse
- Aesthetic terror (ritual, beauty-of-dread) as much as visceral shock

**Working checklist**
- Decide primary shelf early
- Horror dread ladder still helps: terror > horror > revulsion 
- For antihero S&S-dark: tether (code, love, wit) so reader can endure

| Failure | Fix |
|---------|-----|
| “Dark” as pigment only | Add horror structure + fantasy engine |
| Edgy antihero, no tether | Code, love, or wit that costs |
| Grimdark label vs uncanny project | Match comps to actual engine |
| Jump-scare pacing | Slow dread; implication |
| “Dark fantasy” dodging “horror” while only splatter | Pick honest shelf |

## Hard

**Cluster without requiring grimdark**
- Lovecraftian secondary worlds, Rice vampire sympathy, Moorcock Elric, King’s *Dark Tower*, Barker’s fantastical horror — dark fantasy cluster without grimdark’s political thesis
- Wagner/Kane lineage: Gothic warrior fantasy — antiheroic, morally ambiguous secondary-world adventure
- Grant’s “forces beyond understanding” usage sometimes rebrands horror — craft still needs fantastic system/world promise if shelved fantasy

**Dial toward neighbors**
- Rotten institutions + compromise as engine → 
- Ancestral house excavation / lineage secret dominates → 
- Personal pulp + weird magic obstacle → 
- Confirmed ritual/demonology cosmology → 

**When to break unbroken bleakness**
- Contrast is craft, not sellout — unbroken bleakness numbs (same as grimdark craft)
- Sympathetic monster interiors must still hold victims’ cost — both, or theme collapses
