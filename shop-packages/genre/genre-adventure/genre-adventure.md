# Adventure (commercial quest / journey)

Engine: leave the familiar world, cross hostile ground, seize a goal — and return changed. Spectacle serves a core question, not only a map of set pieces.

## Light

Job: answer a core question through hostile travel — every set piece pressures that question.

Contract: physical boon optional; transformation is the real elixir. Personal stakes: if anyone could swap in, investment is wrong.

Must-not-break:
- Clear tangible goal + personal why
- Threshold crossed early enough
- Hostile territory — travel is the plot
- Mid-journey failure that changes tactics or values
- Apparent hopelessness before the win — earned tools from prior failures
- Return (literal or ironic) shows transformation

## Normal

**Quest spine (Booker five stages)**

1. Call / goal named — place, item, person, or MacGuffin that forces leaving home
2. Journey begins — departure from familiar world
3. Hostile territory — obstacles multiply
4. Final ordeals — often clustered (sets of three common in pulp/adventure)
5. Achievement + growth

Hero’s Adventure recipe (WD mapping): call → aid/mentor → threshold → tests/setbacks → regroup → foe vanquished or elixir seized → return / order restored.

**Commercial adventure craft**

- Begin with a core question (human vs nature / technology / unknown)
- Plunge into terrible trouble early; each escape worsens the bind (logical consequences)
- Pair beginning and end (same place / mirrored event) to measure change
- Worldbuilding: reveal setting as it becomes relevant to action
- Well-meaning choices that create disaster keep adventure moral, not tourist

**Set piece discipline**

- Geography clear; fatigue and resource drain matter
- Mentors give what hero lacks — or withhold to force growth
- Quiet regroup beats between bangs

| Failure | Fix |
|---------|-----|
| Set-piece tourism | Core question pressure each ordeal |
| Coincidence escapes | Logical consequence chain |
| Swappable hero | Personal why |
| No return measure | Mirror opening/closing |

## Hard

**Sibling billing**

- Fantasy quest wonder → 
- Frontier psychology / law vs freedom → 
- Pursuit clock dominates → 
- Mission + unit + conscience → (not treasure-map adventure)

**War/military adjacency** (when campaign replaces treasure)

- Briefing → deployment → first engagement → escalation/loss → obedience-vs-conscience → final operation
- Accuracy of ranks/tactics builds trust; jargon as seasoning; story still king

**When to break monomyth completeness**
- Ironic or failed return still measures change
- Pulp ordeal clusters (sets of three) OK if cost escalates
