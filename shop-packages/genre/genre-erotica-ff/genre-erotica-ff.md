# F/F erotica

Engine: **female–female desire as the sexual center** — gaze, pacing, and power must be written for that pairing, not as mirrored M/F with pronouns swapped.

## Light

Job: deliver character-specific F/F desire — mutual agency, not male-gaze residue or newbie-teacher as the only plot.

Contract: apply erotica strip/HEA tests; heat honesty (soft/sensual vs explicit); varied sexual scripts.

Must-not-break:
- Mutual desire specificity — what *this* woman wants from *this* woman tonight
- Avoid male-gaze spectator framing of bodies
- Varied scripts — not only one default act sequence
- Roles (butch/femme, switch, D/s, stone) are character-chosen, not fetish costume without interiority
- Closeting / outing / workplace risk = power stakes, not spice only
- Pairing letters do not auto-make erotica

## Normal

**Genre shape**
- Same structural split: erotica vs erotic romance vs steamy romance
- F/F markets sensitive to male-gaze residue and “one femme teaches one newbie” as the only plot
- Stacks with contemporary, historical, paranormal, kink, etc.

**Reader promises**
1. Mutual desire specificity
2. Varied sexual scripts
3. Emotional risk on page when relevant (secrecy, community, exes, identity); joy-only books valid if marketed so
4. Heat honesty end-to-end

**Consent / power craft**
- Compulsory “perform for male spectator” fantasy usually fails unless diegetically framed — know audience
- Kink F/F: same negotiation standards 

**Craft beyond gender-swap**
- POV filter: who notices scent, strength, softness, competence — avoid cataloguing bodies like product
- Pacing: patience and attention detail often reward; rushing to copied M/F climax shape feels wrong
- Community: friends, queer spaces, ex-networks — useful breath between heat

| Failure | Fix |
|---------|-----|
| Male-gaze description | Desire through character POV; cut spectator framing |
| Newbie + experienced as only engine | Vary power; both have erotic agency |
| Soft marketing + hard explicit (or reverse) | Match heat lane end-to-end |
| “Lesbian until graduation” twist | Don’t use identity as betrayal gag |
| Interchangeable partners | Specific Want/Need + voice |

## Hard

**Gaze and market**
- Soft/sensual F/F vs explicit erotica are different contracts — comps and cover language must match choreography
- Historical / paranormal constraints on women’s autonomy change refusal maps (, )

**When to break “slow attention pacing”**
- Pressure-cooker shorts and high-heat serials can move fast if consent and specificity still hold
