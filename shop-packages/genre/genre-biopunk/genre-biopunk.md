# Biopunk

Engine: **bodies, genes, and biotech as control systems** — synthetic biology, black clinics, and uneven enhancement under corporate or state power; flesh as the hackable substrate (cyberpunk’s sibling, not its costume swap).

## Light

Job: make wetware the trap — genes, tissues, pharma, and clinics create conflict the way chrome/networks do in cyberpunk.

Contract: near-future (or near-future-feeling) SF centered on biotechnology consequences; dark atmosphere common; benefits gated by class/corporation; DIY / hacker ethos against oppressive bio-power.

Must-not-break:
- Substrate is biology (genes, tissues, ecology of the body) — not only neon + DNA screensaver
- Black clinic / unregulated modification space is a signature pressure
- Consent and ownership of organisms are plot, not footnotes
- Limits of the wet science (delivery, immunity, ecology) constrain miracles
- Invincible designer-baby protagonists break the peril contract

## Normal

**Genre shape**

- Portmanteau: biology/biotech + punk; derived from cyberpunk but centered on **biotechnology** rather than cyberware/IT
- Near-future consequences of recombinant DNA / synthetic biology revolution
- Typical antagonists: biotech megacorps, oppressive orgs engineering DNA for control/profit
- Atmosphere often dark: risks, downsides, perils of genetic power
- Di Filippo “ribofunk” — ribosome + funk — related self-label / manifesto lane

**Biopunk vs cyberpunk**

| | Biopunk | Cyberpunk |
|--|---------|-----------|
| Substrate | Genes, tissues, pharma, ecology of the body | Net, chrome, data, street tech |
| Mod | Genetic manipulation / wetware | Cyberware / decks |
| Signature set | Black clinic, chimera, patented life | Sprawl, ICE, megacorp mainframe |

Shared: low-life vs high tech/power; uneven access to enhancement; DIY/hacker ethos.

**Obligatory pressures**

- Consent breach — body altered without meaningful choice, or coerced “choice”
- Patent / ownership — who owns the organism, the clone, the therapy
- Clinic door — crossing into unregulated modification space
- Phenotype bill — side effects, ecological release, horizontal gene spread
- Class reveal — elite bodies vs disposable test populations
- Identity after edit — memory, species boundary, parentage, self-recognition

**Working checklist**

- Plausible enough wet science — or clearly framed speculative biology with consistent rules
- Extrapolate medicine, agriculture, cosmetics, warfare, reproduction — not only supersoldiers
- Avoid magic CRISPR: limits, delivery, immune response, regulation as plot
- Ethics without tract: show harm pathways through character Tuesday
- If using cyberpunk chrome too, decide which system is load-bearing

| Failure | Fix |
|---------|-----|
| Cyberpunk with green lighting | Make gene/clinic ownership the trap |
| Gross-out, no stakes | Tie body horror to institution or want |
| Invincible enhanced hero | Cost every edit; show class gating |
| Ignoring ecology | Edited organisms exist in systems |

## Hard

**Ribofunk / lineage**

- Di Filippo’s ribofunk reframes the lane as funk + ribosome — same wet substrate, different self-brand; useful when comps resist “punk” marketing
- Precursors/touchstones: Wells *Moreau*; Bear *Blood Music*; Sterling *Schismatrix*; Cordwainer Smith scanners; Newitz *Autonomous*
- Body horror adjacency legitimate — keep speculative biology legible ( tools)

**Diagnostics**

| Symptom | Likely cause | Route |
|---------|--------------|-------|
| Neon sprawl, gene as wallpaper | Cyberpunk primary | |
| Lab thriller, no street/class punk | Techno-thriller / medical | |
| Climate via engineered organisms | Cli-fi / eco adjacency | |
| Pure gore, no bio-power | Horror only | |

**When to break “dark atmosphere”**
- Postcyberpunk / hopeful bio-commons possible if uneven power and consent remain dramatized
- Utopian gene-edit without cost → wrong shelf promise for biopunk
