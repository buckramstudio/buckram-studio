# Comedy / satire fiction

Engine: tonal contract + incongruity. Comic novel wants the laugh to deepen character/stakes; satire wants the laugh to make a truth about power (or a social gap) undeniable.

## Light

Job: establish what this world may joke about — and whether the laugh serves character or illuminates a power gap.

Contract: page-level joke craft lives in ; this file is novel-scale stance. Comedy without satirical argument is valuable entertainment; satire without comedy balance becomes complaint.

Must-not-break:
- Establish tonal range early
- Punch up, not down
- Satire: name the true thing in one sentence; research the real gap
- Don’t break satirical voice to wink (“Swift mistake”)
- Humor that replaces cost undercuts stakes

## Normal

**Comic novel vs satire**

| | Comic novel | Satire |
|---|-------------|---------|
| Primary job | Entertain via incongruity; character engine generates laughs | Illuminate gap between official claim and reality |
| Self-test | Does the joke serve scene/character? | Can you name the true thing in one sentence? |
| Without comedy | Still a novel (thinner) | Becomes complaint / pamphlet |
| Without argument | Still comedy | Entertainment only — not satire |

- Deflation engine (satire core): treat trivial as epic *or* epic as trivial (Swift *Modest Proposal* register)
- Joke on power/hypocrisy → satire; joke on the vulnerable → cruelty dressed as wit

**Tone contract**

- A joke that worked in ch. 3 can jar in ch. 15 if it violates the earned contract
- Comic novels can hold grief/violence if rules of the world are taught first
- Satire voice: target in self-incrimination / detached observer / earnest advocate of untenable position — **choose one**
- Modes: deadpan news, mock-official document, mock-academic, satirical letter — commit fully

**Premise before jokes (satire)**

- “[Real situation X] treated as if [incongruous context Y]”
- “[Official claim A], taken to logical conclusion, produces [absurd/horrible B]”
- Target ≠ premise; ground + angle in opening
- Satirical punchline = moment the argument becomes undeniable

**Comic novel architecture**

- Character obsession / blind spot the plot systematically exploits
- Escalation: each stage slightly more absurd, still plausible
- Status reversal + earnestness-vs-scale
- Straight man needs own rigidities — not blank foil
- After devastating beat: restraint → later laugh lands harder

| Failure | Fix |
|---------|-----|
| Explaining the joke | Trust the voice; cut the wink |
| Decorative “parsley” humor | Give each gag a job |
| Punching down | Retarget power/hypocrisy |
| Unresearched satire | Exaggerate a real trait/gap |
| Never risks sincerity | Investment required for laugh |

## Hard

**Balance as craft (satire)**

- Without comedy balance, truth dies or comedy obscures truth — balance *is* the craft
- Inaccurate satire collapses into slander
- Research non-negotiable before exaggeration

**When to break tonal consistency**
- Midbook darkening OK if the rulebook was taught; sudden cruelty without setup breaks trust
- Satire may stay pessimistic; comic novel may restore order — seed which contract you sold
