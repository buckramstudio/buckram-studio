# M/F erotica (unmarked default)

Engine: **male–female sexual journey** — the culturally “default” pairing, which means **heterosexual scripts hide inside craft choices**. Make those choices conscious.

## Light

Job: make M/F desire character-specific — heterosexual scripts are choices to earn or invert, not neutral defaults.

Contract: balanced interiority; sexual becoming or dynamic change; consent modernity; strip/HEA tests still apply.

Must-not-break:
- Specific chemistry — not Everyhusband × Everyheroine
- Balanced interiority so one gender isn’t furniture
- Sexual becoming or dynamic change — erotica spine required
- Consent modernity — silence ≠ yes; power roles named
- Don’t treat female pain as automatic spice
- Pairing letters do not auto-make erotica

## Normal

**Why a separate note**

- Male initiation / female responsive desire as the only pattern
- Penetration-as-climax = scene success metric
- Male pleasure centered; female orgasm as proof-of-performance
- “Alpha” swagger and possession language as default heat 

**Genre shape**
- Same erotica vs erotic romance vs steamy tests as parent files
- Most setting flavors default to M/F in the market — stacking is normal
- Bisexual / m-spec characters in M/F-presenting plots need honest desire history (not “experiment” punchlines)
