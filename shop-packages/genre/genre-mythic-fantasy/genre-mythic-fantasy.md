# Mythic fantasy / mythic fiction

Engine: gods, folklore patterns, and living myth as system — tropes of legend operate with felt inevitability or ritual logic; stories rewrite, inhabit, or punk the old patterns rather than only tour a secondary-world magic system.

## Light

Job: make the old pattern click under the new story — bargains, geasa, and sacred costs bind tighter than ordinary law.

Contract: recognizable myth/legend grammar; standalone completeness; sensitivity for living religions and closed practices.

Must-not-break:
- Know the source well enough to invert it cleanly — shallow name-drops fail
- Pattern click: reader/character recognizes which myth is running
- Bargain / geas with real cost — never free lunch
- Gods as persons with agendas — or impersonal pattern pressure
- Rewrite fulcrum earns divergence from source
- “Mythic” ≠ vague soft magic with no pattern

## Normal

**Genre shape**

- **Mythic fiction** (de Lint / Windling label): tropes/themes/symbolism of myth, legend, folklore, fairy tale — often real-world set; fantastic not always blatant
- Range: straight retellings → motif-new stories loosely inspired
- Overlaps urban/contemporary fantasy; non-urban mythic settings count
- Differs from magical realism when symbolism is explicitly myth/legend-rooted rather than surreal-random
- **Mythic fantasy** (shelf talk): secondary-world or heroic tales where gods/myth patterns are diegetically real

**Mythpunk (sharpened edge)**

- Valente coinage: folklore/myth + postmodern technique; subvert dominant norms (often feminist/multicultural)
- Transform source material, don’t only retell — nonlinear, confessional, linguistic play
- Folklore as battleground between subversive and conservative forces (El-Mohtar)

**Conventions & pressures**

- Ritual, taboo, triple tests, katabasis, sacred kingship, animal helpers — used with intent
- Language elevated or folk-plain by design; names matter
- Obligatory: pattern click; bargain/geas; underworld/otherworld turn; hubris bill; rewrite fulcrum; return with sacred scar

| Failure | Fix |
|---------|-----|
| Pantheon encyclopedia, no human want | Character GMC under pattern |
| Exact retelling + modern slang, no angle | One-sentence innovation angle |
| Appropriation tourism of sacred narrative | Research; closed practices off loot table |
| “Mythic” = vague soft magic | Felt ritual logic / pattern |
| Symbols without scenes | Dramatize; don’t lecture resonance |

## Hard

**Mythic fiction vs god-epic vs retelling**

- Comps must say which: quiet mythic atmosphere, fairy-tale retelling contract, or living-pantheon epic
- Secondary-world pantheon: theology has economics and weather 

**When to break fidelity**
- Mythpunk transformation can shatter tale-type order — still need emotional clarity so readers aren’t only puzzled
- Living religions: careful translation or conscious replacement — not generic fairy dust ( cultural context)
