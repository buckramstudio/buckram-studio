# PI / lone detective

Engine: a private investigator (or functional loner) works a case outside institutional power — personal code vs corrupt world. Case + cost to the sleuth.

## Light

Job: pull one client thread until systemic rot shows — personal code tested; solved ≠ healed.

Contract: protagonist is not the institution; case larger/dirtier than advertised; voice sharp.

Must-not-break:
- Client walk-in (or equivalent) starts the job
- Personal code of honor tested — acts against self-interest under pressure
- World: systemic corruption more than one “bad apple”
- Ending often partial justice — moral ledger clear even if loose ends remain
- Case solution costs something the PI valued
- Avoid costume noir (fedora without moral weather)

## Normal

**Genre contract**

- Freelance, ex-cop, agency of one, or unofficial fixer
- Voice frequently first-person hardboiled; third-person OK if perception stays sharp

**PI vs puzzle detective vs procedural**

| Mode | Engine |
|------|--------|
| Golden Age puzzle | Fair-play deduction; closed circle |
| Police procedural | Institution, procedure, team |
| PI / hardboiled | Stir the pot; expose rot; instinct + nerve |
| Noir interior | Psychic damage / compulsion as focus  |

PI can host a locked-room puzzle, but brand promise is the loner’s cost, not the physics trick.

**Protagonist craft**

- Grinder, not eccentric genius — competence from attention, contacts, stubbornness
- Flawed but on the side of (personal) good; often former institutional actor pushed out
- Code moments: acts against self-interest — prove the code
- Optional helpers deepen the book even if “lone” branding remains
- Contemporary PI: databases, legal players, surveillance without lecture dumps

**Plot architecture**
- Pull one thread → tapestry of corruption (true antagonist often the system)
- Client / “femme fatale” (any gender) as promise + threat
- Escalate: warnings → violence → no safe exits
- High stakes + clock when hybridizing thriller
- Dialogue as weapon/shield 

| Failure | Fix |
|---------|-----|
| Costume noir, no moral weather | Code + systemic rot |
| Institution solves the case | Keep PI outside / in tension with power |
| Solved = healed | Partial justice; personal cost |
| Infodump research | Texture in scene under pressure |
| Puzzle physics without loner cost | Choose locked-room shelf or add code cost |

## Hard

**Code as structure**

- State code under pressure, then crack or pay for it — mastery is the ledger, not the fedora
- System as antagonist: name institutional spine early, not only the corpse

**When to break lone branding**
- Partner/agency series: keep personal code load-bearing or you drift into procedural
- Fair-play hybrid: if howdunit becomes the brand, see / — don’t bait PI readers with pure puzzle coldness
