# Survival adventure

Engine: environment as antagonist; skills, luck, and will under scarcity; the plot is staying alive long enough for a harder choice to appear.

## Light

Job: make the resource ledger and environment rules the engine — competence under scarcity, not invincible MacGyver tourism.

Contract: danger outside ordinary life; pace and ordeal at least as important as setting postcard; overlap Robinsonade / sea / polar / disaster lanes when isolation + skill decide fate.

Must-not-break:
- Resource ledger visible: water, calories, warmth, injury, tools
- Knowledge as plot: wrong folklore kills; earned skill saves
- Weather and terrain turn on a schedule — coincidence only if seeded
- Human conflict optional but potent (who shares the last water)
- Rescue / extraction ending costs something or transforms the survivor
- Don’t claim realism while ignoring hypothermia / infection basics

## Normal

**Genre shape**

- Adventure focus (D’Ammassa): danger outside ordinary life; pace of plot at least as important as characterization — survival lane makes *environment* the chief danger
- Modes: wilderness, sea (Robinsonade adjacency), disaster, polar, desert, space-as-environment (non-military)
- Overlaps lost-world / expedition  when discovery + isolation braid
- Can be literary (interior ordeal) or commercial (set-piece ordeal)

**Working checklist**

- Environment antagonist with rules (cold, desert, sea, jungle)
- Competence test — skill learned or fatally faked
- Isolation or mistrust among survivors
- False sanctuary that fails
- Escape / rescue / acceptance earned by changed capability or alliance
- Quiet consequence after ordeal (scars, changed priorities)

**Obligatory pressures / moments**
- Environment as antagonist
- Resource ledger ticking down
- Competence test
- Isolation / mistrust
- False sanctuary
- Escape / rescue / acceptance with cost

| Failure | Fix |
|---------|-----|
| Invincible MacGyver | Force mistakes; show unlearning |
| Nature-doc pause | Turn weather/terrain on a seeded schedule |
| Realism claim, fantasy body | Respect infection / cold / dehydration ceilings |
| Ordeal forgotten after rescue | Carry scars into the next want |

## Hard

**Sibling billing**

- Treasure/map quest pleasure → adventure parent
- Hidden civilization + wonder → lost-world
- Ship society + sea economy → 
- Stay here when scarcity math and environment rules bill first

**Robinsonade / isolation spectrum**

- Solo vs group changes the moral engine (self vs sharing ledger)
- Literary survival may slow pace for interior ordeal — still needs ledger turns, not essay pauses

**When to break competence fantasy**
- Luck may save once if seeded; repeated luck breaks the skill contract
- Acceptance / death endings valid if transformation still measures change
