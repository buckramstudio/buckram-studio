# Novel process (plan → draft → revise)

How to write a novel at all — not AI-specific. Distilled from One Stop / Writers Helping Writers Storyteller’s Roadmap materials.

## Light

Job: finish a draft by separating plan, write, and revise into manageable stages.

Contract: pick an entry door (character, plot, or setting); assess before rewriting everything.

Must-not-break:
- Three stages: Plan → Write → Revise (don’t conflate)
- Finish a draft before endless outline restarts
- Outer plot must marry inner arc
- Revision in rounds — not one pass that fixes everything
- Pantsers still need structure basics (apply in revision if not in outline)
- Process problems (block, middle, doubt) are part of the roadmap, not only craft failures

## Normal

**Three stages**
1. **Plan** — concept, plot, characters, world (Planning Checklist)
2. **Write** — goals, motivation, survive first-draft derailments (block, self-doubt, procrastination, lost in the middle)
3. **Revise** — First Draft Health Assessment → managed rounds of edit/feedback/polish

Titans to start with: **character, plot, or setting** (pick one entry door).

**Starter habits (Reedsy distillations)**
- Read widely and in your genre; journal for unfiltered voice
- First novel: write the book you want to read; finish a draft
- Community aligned with path (trad vs self-pub); rejection = send-next
- Feedback: thick skin + extract craft; weave description into action

**Drafting / revision stance**
- Keep arc blueprints beside the manuscript so outer plot mirrors inner journey
- Assess first (health assessment / challenge questions) before rewriting everything
- Elevate each character, element, event in rounds; thesaurus to replace fluff with meaning

| Failure | Fix |
|---------|-----|
| Endless outlining | Draft deadline; Snowflake mid-draft OK |
| One giant revise pass | Health assess → rounds |
| Plot with no character | Tailor events to unsuited-to-win growth |
| Character with no plot pressure | Catalysts that force leaving old life |

## Hard

**Snowflake as design ladder**
- One-sentence → one-paragraph (3 disasters + ending) → character sheets → expanding synopses → scene spreadsheet → draft
- Details: . Works mid-draft/rewrite too (elevator sentence first).

**Planning toolkit (what each surface is for)**

| Tool | Job |
|------|-----|
| Character Builder | Past/present; Character Arc Blueprint |
| Light character notes | Pantser “at a glance” before deep tabs |
| Story Maps | Macro outline (Six Stage / Hauge-style) |
| Scene Maps | Micro: goal + stakes + arc movement |
| Timelines | Events, dual tracks, reveals, subplots |
| Worldbuilding surveys | Logic of place/people/systems |
| Idea Generator | Wounds, complications, stakes, prompts |
| Setting worksheets | Location + emotional value |
| Thesaurus | Mid-draft show options |

**Plot vs character entry**
- **Plot-first:** events that batter toward a goal; invent a character unsuited to win without growth
- **Character-first:** everyday struggles → catalysts that force leaving the old life
- Either way: story is ultimately about the **character**; plot tailored to them
- Outer story (plot) + inner story (arc) married by structure
