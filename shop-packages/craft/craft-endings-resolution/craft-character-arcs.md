## Light

Job: align outer plot with inner change via Lie, Truth, Want, Need, and Ghost.

Contract: the protagonist’s final relationship to the Truth *is* the theme proved.

Must-not-break:
- State the Lie in one short sentence
- Want (external) ≠ Need (usually the Truth)
- Ghost made the Lie feel necessary
- Normal World shows Lie working before Adventure World breaks it
- Arc type chosen on purpose (positive / flat / negative)
- Midpoint Moment of Truth is the hinge for seeing it

## Normal

**Six ingredients (all arcs)**
1. **Thematic Truth** — what the story posits about how the world works
2. **Lie the character believes** — misconception that blocks the Truth
3. **Want** — external plot goal
4. **Need** — usually the Truth (may take physical form)
5. **Ghost (wound)** — backstory catalyst that installed the Lie
6. **Normal World** — First Act life; Truth- or Lie-coded

Notes: Lie often *worked* in the Normal World; Want vs Need = outer vs inner conflict; Ghost (Truby) can even be a “positive” event that smothered growth.

**Five arc types (at a glance)**

| Arc | Spine |
|-----|-------|
| **Positive-Change** | Believes Lie → overcomes Lie → Truth liberates |
| **Flat** | Believes Truth in Lie-ridden world → maintains Truth → changes the world |
| **Disillusionment** | Overcomes Lie → new Truth is tragic/jading |
| **Fall** | Clings to Lie → rejects Truth → worse Lie → destruction |
| **Corruption** | Sees Truth → rejects it → embraces Lie |

**Practical checks**
- Incomplete inside, not because of missing external toys
- First Act demonstrates Lie entrenchment before plot peels defenses
- Positive Change: person who believed the Lie must “die” into Truth-integrated identity

| Failure | Fix |
|---------|-----|
| Lie too vague | One sentence, qualifiers OK |
| Want = Need | Separate plot prize from thematic Need |
| Ghost never on page | Dramatize residue  |
| Arc sticker at end | Prove via Climactic action |

## Hard

**Beat spines (Weiland % approx — Positive-Change)**
Hook believes Lie → Inciting hints Lie failing → 1PP Door of No Return → Pinch1 punished for Lie → Midpoint sees Truth but doesn’t reject Lie → Pinch2 rewarded for Truth → 3PP rejects Lie → Climax embraces Truth → Climactic Moment uses Truth to gain Need → Resolution Truth-empowered Normal World

**Flat / Negative hinges**
- Flat: Want ≈ Need often; Midpoint proves Truth’s power to the world; Climax Truth vs Lie
- Fall: Midpoint glimpses Truth, rejects for worse Lie; Climactic Moment total destruction
- Corruption: starts understanding Truth; Midpoint embraces Lie without fully rejecting Truth; Climactic Moment moral failure
- Disillusionment: same growth mechanics as Positive Change, but Truth is cold; bridge toward redemption or bitterness

**Theme link**
- Positive Change / Flat celebrate Truth; Negative reject or sour on it
- Third Act proves the relationship; Midpoint Moment of Truth is the hinge
