# Epistolary and documents-as-narrative

Letters, emails, chats, reports, and found documents as engine — not garnish.

## Light

Job: make documents carry drama via writer agenda, audience, and blind spots.

Contract: text exists diegetically inside the characters’ world — realism + multiperspective without omniscient glue.

Must-not-break:
- Who writes to whom, why *now*? (Want in the act of writing)
- Each document performs / hides something
- Gaps between documents change the next tone
- Fair plants in letterhead, dates, omissions, CC lines
- Exhaustion test: vary medium and power if every chapter is “Dear X”

## Normal

**Why documents**
- Greater realism: documents live inside the story world
- Differing viewpoints without omniscient narrator
- **Fictional editor** device can stage authenticity (papers “found/arranged”)
- Hybrid OK: letters + diaries + clippings + modern email/blog/recordings

**Voice count (classical types)**
| Type | Pattern | Note |
|------|---------|------|
| **Monophonic** | One writer | Werther / Portuguese Nun |
| **Dialogic** | Two writers | Dual agendas |
| **Polyphonic** | Three+ | *Dracula*, *Clarissa* — richer irony |

**Design checklist**
1. Who writes to whom, why now?
2. What do they hide / perform?
3. Gap between letters: off-page events
4. Fair plants (, )
5. Still need turn/cost when hybridized with scenic chapters 

**Media texture**

| Form | Strength | Trap |
|------|----------|------|
| Letter | Reflection, delay, formality | Victorian throat-clear |
| Email / text | Speed, misunderstanding | Slang walls |
| Chat log | Overlap, silence as beat | Timestamp spam |
| Official report | Cold irony vs human cost | Infodump cosplay |
| Diary | Intimacy / self-lie | No external pressure |

| Failure | Fix |
|---------|-----|
| Documents only dump exposition | Give each a dramatic Want |
| Identical voice across writers | Differentiate agenda + diction |
| No scenic body — fatigue | Hybridize with embodied scenes |
| Frame never pays off | Convergence / discovery climax |

## Hard

**Discrepant awareness (polyphonic engine)**
- Simultaneous separate correspondences (heroine vs villain strands in *Clarissa* / *Dangerous Liaisons*) create dramatic tension via what each circle doesn’t know
- Sequence need not relate events directly — reader assembles chronology (Laclos effect)
- Letters that fall into wrong hands / faked / withheld = intrigue toolkit (early Behn tradition)

**Frame & authenticity edges**
- Fictional editor / collector (*Moonstone*-style “gathering the true story”) must itself have motive
- Nested frames (*Frankenstein* captain letters → Victor narrative; *Wildfell Hall* letter + diary) — each layer needs a job
- Modern poly-document (*Dracula*: letters, diaries, clippings, telegrams, logs) — still monophonic risk if every voice sounds like the author

**Satire / fatigue history**
- 18th-c popularity → burlesques (*Shamela*: writing under absurd circumstances) — warn against diary-during-crisis comedy unless intentional
- Form declined after 18th c.; survivals are often hybrid or fragment — pure letter novels need strong Want/variation to avoid museum piece
