Builder card: .

## Light

Job: turn past hurt into present shielding that blocks the outer goal until growth (or tragic refusal).

Contract: page-one personality is wound-shaped; story pressure forces the shield to fail so the unmet need can be faced.

Must-not-break:
- Wound → Fear → Lie → Shielding → Unmet need → Outer goal (chain stays causal)
- Shielding looks like “personality” until it backfires
- Outer adversary repeatedly triggers the greatest fear
- Reveal via action/dialogue/body — not dump 
- Fatal flaw = cognitive + behavioral pair that blocks the goal

## Normal

**Causal chain**
1. **Emotional wound** — past negative event (single trauma, long situation, or “death by a thousand cuts”) deep enough to change who the character is
2. **Fear** — all-consuming “never again” drive to avoid repeating the pain
3. **False belief / Lie** — often self-blame or world-distortion that “explains” how to stay safe
4. **Emotional shielding** — flaws, habits, attitudes, biases adopted as protection (actually dysfunctional)
5. **Unmet need** — one of Maslow’s basics compromised (safety, love/belonging, esteem, self-actualization…); creates a void
6. **Story present** — outer goal chosen (often unconsciously) to refill the void; inner conflict = greatest fear blocking that refill

**Wound → shielding forms**

| Shielding form | What it looks like | How it backfires |
|----------------|--------------------|------------------|
| Flaws / trait shifts | Control, apathy, uncooperativeness after harm | Ancillary life problems; hard to succeed |
| Dysfunctional behaviors | Hypercritical demands, withdrawal, withholding ideas | Relationships + goals damaged |
| False beliefs | “If I’d been worthier / more careful…” | Self-worth collapse; dreams feel unreachable |
| Biases | “All X are dangerous / no adult respects kids…” | Blocks healthy relating |

Also ask: which **positive** traits does she *downplay* because she thinks they caused the wound (trust, kindness, obedience…)?

**Fatal flaw (two prongs)**
**Fatal flaw** = antiquated approach to life that must be adapted/cast aside for success. Always a form of emotional shielding.

- **Cognitive:** bias / mindset / disempowering belief that blocks the story goal
- **Behavioral:** the habit that enacts that belief on the page

Protocol:
1. Name the wound
2. Name the Lie that grew from it
3. List all shielding (behaviors, biases, negative ideas)
4. Pick the cognitive piece that most blocks the goal
5. Pick the matching behavioral piece that trips them all story long
6. Design failure patterns + small wins so they can see/renounce it (or succumb — negative arc)

Example spine (*Finding Nemo* / Marlin): wound = family slaughtered → Lie “world is deadly” → behavior = smothering control → unmet Love/Belonging with son → arc = trust + allow responsible risk.

**Backstory → current-story map**

| Backstory piece | Current-story piece |
|-----------------|---------------------|
| Wound + fear + Lie + shielding + unmet need | Who they are on page one |
| Unmet need (void) | **Inner motivation** (why *this* outer goal) |
| Outer adversary / force | **Outer conflict** (triggers fear repeatedly) |
| Greatest fear | Primary **inner conflict** until faced |

Two starts: already deficient/stuck; or “best life” then void opens. Outer goal should be a plausible path to fill the missing need — fear then sabotages that path until faced.

**Emotion on the page (beat craft)**
Don’t name the feeling as the main move. Weave:
- Physical signals (posture, movement, expression)
- Internal/visceral sensations
- Mental responses (thoughts, urges, fixations)
- Speech + nonverbal dialogue cues
- Longer-term cues (lingers / escalates / dissipates)

**Repressed emotion** (shielding in the moment):
- Over-/under-reactions vs established baseline
- Character-specific tics/tells when hiding
- Fight / flight / freeze micro-moves in conversation
- Passive-aggression (sarcasm-as-joke, backhanded compliments) + private leak after
- Incongruence: polite words vs body that refuses welcome

Avoid cliché stacks (always racing hearts / nodding / sighing). Match intensity + personality; vary channels across beats. Pair with MRUs: stimulus → feeling → reflex → deliberate action .

**Quick character card (fill before drafting)**
- Wound (one sentence, age/context)
- Greatest fear
- Lie / false belief
- Shielding list (flaw + 2–3 habits + any bias)
- Fatal flaw (cognitive + behavioral)
- Compromised need (name one)
- Outer goal that (seems to) refill the need
- How plot *triggers* the wound this chapter
- What the body does when the character pretends they’re fine

| Failure | Fix |
|---------|-----|
| Wound as bio only | Tie to shielding that blocks *this* goal |
| Dump flashback | Show trigger + body + avoidance first |
| Flaw random | Link cognitive + behavioral to Lie |
| No unmet need | Name Maslow gap; aim outer goal at it |
| Identical repression tells | Character-specific tic; vary channels |

## Hard

**Thesaurus entry anatomy (planning aid — fair-use concepts)**
Per wound brainstorm: forms the trauma can take false beliefs fears/insecurities dysfunctional coping traits that bloom triggers paths toward overcoming.
On-page reveal preference: action, dialogue, body language, avoidance — not backstory dumps.

**Negative vs positive arc fork**
- Positive: recognize shielding → small wins → renounce fatal flaw → need met (or newly chosen)
- Negative / tragic: double down on Identity; “win” outer goal while unmet need worsens — or refuse the leap 
- Flat arc: already Essence-aligned; wound pressure tests *others* or the world — shielding may be society’s, not the hero’s

**Romance / intimacy cross-lane**
- Partner who sees behind the armor = Hauge perfect-match pressure 
- Intimacy scene: does sex/closeness threaten or soothe the unmet need? 
- Dual wounds that rhyme too neatly can feel schematic — offset timing and shielding forms

**Advanced diagnostic**
| Symptom | Cause | Tool |
|---------|-------|------|
| Reader unsympathetic to self-sabotage | No early wound hint | Seed by ~25%  |
| Arc feels therapized | Named feelings / lectures | MRU + repressed-emotion channels |
| Goal arbitrary | Outer goal ≠ void refill path | Rebuild motivation map |
| Flaw flips overnight | No failure patterns / small wins | Design mid-book experiments with mask off |
| “Trauma dump” mid-climax | Complex past + complex present | Prefer simple wound statement; dramatize one formative beat |

**When to break the chain**
- Some characters wound each *other* in-story (no deep childhood required) — still name the resulting Lie/shield
- Ensemble: not every supporting role needs full thesaurus depth — give one vivid shield tell
- Comedy may underplay trauma vocabulary while keeping functional shielding (avoidance, bias, fatal habit)
