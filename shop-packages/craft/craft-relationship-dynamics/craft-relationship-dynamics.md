# Relationship dynamics / chemistry on the page

How bonds *behave* in scene — status, intimacy gradients, ally/rival/lover triangles. Chosen-bond engine: . Romance beats: .

## Light

Job: make pairs anticipate-able — readers lean toward the next interaction because status and intimacy are moving.

Contract: chemistry is not romance-only; each major bond has contrast, private language, and stakes if it fractures.

Must-not-break:
- Individuals first — each has goals outside the dyad
- Status is *done* in the encounter (Johnstone), not only social rank
- Intimacy advances by rung with cost — or withdraws as signal
- Action over announcement of closeness
- Triangles need viable poles + a living A↔B between poles

## Normal

**Chemistry ≠ romance only**
Chemistry = connection that makes readers anticipate the next interaction — love, friendship, rivalry, respect (Sam/Frodo, Holmes/Watson, Harry/Draco as non-romantic charge).

Build intentionally:
- **Contrast** — opposing beliefs/tempos; gaps each fills; blur rival ↔ unlikely friend
- **Dialogue** — banter type; speech patterns differ; subtext in dodge/humor; talk *changes* as bond shifts
- **Action over announcement** — fairness from a rival, mentor’s push, small gestures, proximity/distance habits
- **Individuals first** — not two halves of a plot appliance
- Relationship tropes as engines — twist while keeping core promise 

Stakes scale with chemistry: readers care whether friendship fractures, rivalry kills, or the bond transforms.

**Status games (Johnstone)**
Keith Johnstone (*Impro*): **status is something you do** in an encounter — not the same as social rank. No neutral status; difference is always present. Drama can live in weather-talk if status shifts every line; life-and-death talk is dull if status is flat.

| Channel | Higher-status play | Lower-status play |
|---------|--------------------|-------------------|
| Movement | Still head, focused, graceful | Jerky, nervous, awkward |
| Speech / pitch | Controlled; often lower/relaxed | Fast, faltering, higher/forced |
| Space / touch | Takes center; unasked touch | Shrinks; tolerates or flees touch |
| Gaze | Steady, socially timed | Averts; or inappropriate stare |
| Problems | Assumes solutions; priorities clear | Sees problems everywhere; rattled |

Raise/lower tactics: exalt self vs diminish other; mothering vs self-incapacitation; praise/abuse; height and vicinity games. High status ≠ arrogance — polite, quiet power often reads higher. Favorite comedy: low social rank playing high behavioral status (and reverse).

Fiction uses:
- Track who initiates distance, interruption, topic change, touch
- Mid-scene status flip = beat
- Pair with want/block/tactic scenes: status can be the *invisible* game under either model

**Intimacy gradients**
Intimacy is a ladder (and can reverse). Axes per pair (not only lovers):

| Axis | Cold → hot examples |
|------|---------------------|
| Information | Public facts → private history → shame/secret |
| Body | Formal distance → casual touch → caretaking → erotic |
| Speech | Performative → banter → unfinished sentences → silence that trusts |
| Obligation | Transactional → favor → risking reputation/safety for them |
| Future talk | None → hypothetical we → concrete plans |

Craft:
- Advance one rung per charged scene; don’t jump cold → confession without cost
- Withdrawal is as intimate a signal as approach
- Mismatch: A at “shared secrets,” B at “colleagues” → conflict without villains
- Show via behavior, not labels 

**Scene tests**
- Cover names: can you tell the pair by *how they take space and turn*?
- Did status or intimacy move this scene, or only plot info?
- If you removed the romance label, would the dynamic still be interesting?
- Does each major relationship have a private “language” (joke, ritual, sore spot) that evolves?

| Failure | Fix |
|---------|-----|
| Flat life-and-death talk | Add status flips line-to-line |
| Announced closeness | Replace with gesture / risk |
| Instant confession | Climb intimacy ladder with cost |
| Dyad as plot appliance | Give each solo goals |
| Triangle with one dummy pole | Make both interests viable |

## Hard

**Romantic triangle (Andrea Max / WD anatomy)**
1. Both interests **viable but not perfect** — if one is obviously right, it’s a delay, not a triangle
2. Ask “who is the protagonist *with* each?” not only “who wins?” — triangle externalizes internal crossroads
3. **Conflict > spark** — each connection challenges values/self
4. Interests as **foils** — different vulnerabilites and futures
5. Let the reader flip-flop — Team A/B whiplash is the engine

Fantasy of abundance / identity rehearsal; once romantic tension fully resolves, momentum tax rises.

**Non-romantic triangles (same geometry)**
- Protégé torn between two mentors (method vs ethics)
- Crime partners + the one who wants out
- Found-family loyalty vs blood loyalty vs mission
- Two friends competing for one scarce resource

Rules that still hold: each pole reveals a different self; the third relationship (A↔B between the two poles) must exist — ignore it and the structure collapses into two parallel dyads; resolution should prove character growth, not coin-flip convenience.

**Status × intimacy cross diagnostic**
| Pattern | Reading | Risk |
|---------|---------|------|
| High status + rising intimacy | Mentor/protector charge | Power imbalance honesty |
| Low status + rising intimacy | Vulnerability as approach | Pity vs desire confuse |
| Status war, intimacy freeze | Rivalry engine | Exhausting without thaw or cost |
| Intimacy jump + status flat | Chemistry claim without behavior | Add body/space/gaze tells |

**When to break ladder pace**
- Crisis can force a rung jump (shared near-death secret) — pay with aftermath mismatch or new obligation
- Long marriage / established crew may start mid-ladder — still show micro-moves, not static “already close”
