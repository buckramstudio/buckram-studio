# Subplot and parallel-plot craft

Weaving A/B/C plots so secondary threads pressure the spine.

## Light

Job: give secondary threads a reason to exist — pressure the same wound/theme from a new angle.

Contract: remove the subplot — if climax emotional logic doesn’t weaken, it was filler.

Must-not-break:
- Earn space by pressuring the same internal wound / thematic question
- ≥2 intersections where B changes A’s options (not mere adjacency)
- B must touch the climax (tool, ally, wound, info, or moral cost)
- Don’t call a second engine a “subplot” if stripping it kills the shelf contract
- Mid-book: B can move while A stalls — B must not become a second novel

## Normal

**Earn the page**
- Unrelated “channel-surf” thread = cut or demote to texture
- Romance fear-of-commitment subplot must force commitment choices in the main plot, or cut

**Jobs a subplot can do**

| Job | Example |
|-----|---------|
| **Mirror** | Secondary couple / quest echoes the protagonist’s Lie |
| **Contrast** | Ally solves the same problem the opposite way |
| **Complicate** | B-plot choice burns a resource the A-plot needs |
| **Relief valve** | Tone breath — still needs micro-tension  |
| **Theme proof** | Prove Truth via a smaller arena before climax  |
| **Cast life** | Secondary has own GMC  |

**Weave rules**
1. Name A (spine), B, optional C — one sentence Want + opposing force each
2. Schedule **≥2 intersections** where B changes A’s options
3. B must **touch the climax**
4. Alternate emotional polarity / pace so B isn’t a copy of A’s beat shape
5. Cap C-plots; hierarchical default for commercial shape

**Parallel plots (beyond “subplot”)**
- **Parallel:** two spines of similar weight — braid like dual-engine or dual-timeline
- **Hierarchical:** clear A with satellite B/C — default commercial shape
- Dual-timeline is a *time* braid, not automatically a subplot

| Failure | Fix |
|---------|-----|
| Subplot vanishes for 100 pages | Reschedule intersections or cut |
| Climax ignores B entirely | Give B a load-bearing chip in the finale |
| Theme lecture in B while A is pure plot | Align pressure on same wound |
| Romance/comedy B never costs A | Force a tradeoff scene |

## Hard

**Pinch-point hitch (mid-book ops)**
- First Pinch (~37%) / Second Pinch (~62%) can *be* subplot intersections that remind antagonistic power or cost 
- Best B-moves create distinctive moments that influence scenes until the next Plot Point — not cameo banter
- If A stalls in Act Two, B should still escalate *toward the same wound* — channel-surf B is still clutter even if “busy”

**Theme / Lie binding**
- Mirror/contrast subplots are Lie/Truth laboratories at lower stakes 
- Resolution craft: resolve as many subplots as possible *before* Climax so denouement stays lean 
- Vanished subplot at end = broken promise chain

**Engine vs satellite diagnostic**
| Test | Result |
|------|--------|
| Strip B; shelf pitch still intact | Satellite (true subplot) |
| Strip B; category promise dies (e.g. RS without romance) | Second engine → |
| B never changes A’s options | Texture or cut |
| B touches climax only as cameo hug | Not load-bearing — raise cost or cut |
