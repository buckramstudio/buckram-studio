# K.M. Weiland story structure (% map)

Cross-genre beats from Helping Writers Become Authors.

## Light

Job: place major structural turns on a flexible percentage map so pacing doesn’t clump.

Contract: nine major moments ≈ equidistant; timing flexible within ~5% if pacing feels right.

Must-not-break:
- Hook early; don’t open with Inciting if Normal World + Lie need space
- Inciting Event asks a dramatic question Climactic Moment answers
- Midpoint is a Second Plot Point — new information / shift, not just “more stuff”
- Third Plot Point ≈ low/defeat before climax climb
- End with the conflict most prominent in the Inciting (inner vs outer)

## Normal

**Nine major moments**

| Beat | ~% |
|------|-----|
| Hook | 1% |
| Inciting Event | 12% |
| First Plot Point | 25% |
| First Pinch Point | 37% |
| Midpoint (Second Plot Point) | 50% |
| Second Pinch Point | 62% |
| Third Plot Point | 75% |
| Climax | 88% |
| Resolution | 98% |

Three acts; Scene/Sequel micro: Goal→Conflict→Disaster / Reaction→Dilemma→Decision .

**Inciting ↔ Climactic pairing**
- Inciting ≈ Call to Adventure (~12%): first definite ask to engage conflict; usually resisted
- Don’t open ch.1 with it if you can help it — first half of Act 1 sets Normal World + Lie
- Climactic Moment answers the question the Inciting asked; bookends main conflict
- Antagonistic force present (or proxied) at climax; at least implied by Inciting
- Theme: Lie at Inciting ↔ Truth at Climactic; optional recurring imagery

**Ordering final conflicts**
- End with the conflict most prominent in the Inciting Event
- Climactic Moment (~95–98%) answers that dramatic question; Third Plot Point (~75%) is the low/defeat

| Failure | Fix |
|---------|-----|
| Inciting on page 1, no Normal World | Delay ask; establish Lie |
| Midpoint is just a bigger chase | Force new information / re-commitment |
| Climax answers a different question than Inciting | Realign bookends |
| Pinch points are random danger | Make them antagonistic reminders of stakes |

## Hard

**Lie / Truth structural binding**
- Inciting pressures the Lie; Climactic Moment proves relationship to Truth (embrace/reject) in a way that changes outer conflict (, )
- Midpoint: Truth appears as concrete antidote to *this* Lie; character often tries to hold Lie + Truth together
- Positive / Negative / Flat arc types = different thematic outcomes at the same % skeleton

**Pinch-point craft (sagging-middle defense)**
- Pinch Points emphasize antagonistic power — not random obstacles
- First Pinch (~37%) reminds cost after First Plot Point commitment
- Second Pinch (~62%) after Midpoint reorientation — raises pressure toward Third Plot Point defeat
- Pair with try/fail that costs internally 

**Flexibility vs cheat**
- ±~5% OK when emotional pacing demands; collapsing Midpoint into First Plot Point is not “flexibility”
