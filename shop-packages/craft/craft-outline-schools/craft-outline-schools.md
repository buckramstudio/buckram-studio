# Outline schools comparison

Plotter / pantser / plantser is a dial, not a moral ranking. Pair temperament with the right **artifact** at the right **phase**.

## Light

Job: pick an outlining artifact that matches how you invent — so structure and spark both survive.

Contract: wrong tool for temperament = stalled book (plotting kills spark *or* pantsing writes into a corner).

Must-not-break:
- Temperament is a dial, not a virtue ranking
- Artifact must match phase (plan ≠ reverse-diagnose)
- Reverse outline is built **from** draft — not a planning outline
- Don’t polish a zero draft into a fake “first draft”
- Don’t outline forever without becoming draft

## Normal

**Temperaments**

| Label | Also called | Needs | Draft tendency | Revision tax |
|-------|-------------|-------|----------------|--------------|
| **Plotter** | Architect | Blueprint before prose | Cleaner structure early | Emotional heat / discovery later |
| **Pantser** | Gardener | Discovery while writing | Energy, surprise | Structure, holes, consistency |
| **Plantser** | Middle way | Signposts + room to leap | Usually closer to goal | Pacing / tension polish |

**Artifacts**

### Full / fractal outline (plotter-native)
- Snowflake steps, scene spreadsheet, STC/Weiland beat sheet with scene lists
- Use when: high-stakes continuity (mystery, multi-POV, series), little rewrite budget
- Trap: outlining forever; outline that never becomes draft

### Signpost / plantser outline
- Know ending + 3–5 disasters / tent poles; leave connective tissue open
- Use when: orientation without killing joy
- Maps onto Weiland major moments or STC foundation beats

### Zero draft (tell-yourself-the-story)
- Between outline and first draft: slapdash prose, bullets, or friend-summary voice
- Goal: whole story exists; **tell**, don’t show; ignore line craft
- Rough scale tip: ~1 page per 1k eventual words (Grimes) — heuristic, not law
- Trap: polishing the zero draft into a fake “first draft”

### Skeleton / fat outline
- Fast narrative of plot only; skip description/voice except what’s needed to move
- Exposes pacing nerves early (slow sections can’t hide behind pretty sentences)

### Reverse outline (pantser-native revision tool)
- Built **from** the draft: one line per scene — what happens + what **changes**
- Use when: discovery draft exists; structure must be found
- Diagnostic, not a planning outline (see )

**When to use which**

| Situation | Prefer |
|-----------|--------|
| Blank page terror | Light signposts or STC foundation five |
| Planning kills spark | Draft → reverse outline → rebuild |
| Lost in Act Two | Zero draft of middle→end *or* STC Fun and Games→Midpoint |
| Complex mystery / series | Plotter tools + continuity bible |
| Edit letter / hopeless draft | Snowflake from step 1 *or* reverse outline + beat overlay |
| Need speed without structure debt | Skeleton/fat outline then expand  |

| Failure | Fix |
|---------|-----|
| Spark dead in outline | Drop to signposts or draft → reverse |
| Cornered at 50k | Zero draft end-path or beat overlay |
| Pretty slow middle | Skeleton expose pacing nerves |
| “I outlined” but no draft | Time-box outline; write |

## Hard

**Phase pairing (practical)**
1. **Ideation** — one sentence + one paragraph (Snowflake 1–2) for everyone
2. **Pre-draft** — plotters: beat sheet + scene list; pantsers: skip or tiny signposts; plantsers: ending + disasters
3. **Draft** — write forward; park research holes 
4. **Post-draft** — reverse outline → structural pass  → genre obligations 

**Temperament traps (edge)**
- Plotter revision tax: structure clean, emotional heat missing → discovery passes after blueprint
- Pantser revision tax: energy high, holes abound → reverse outline is mandatory, not optional
- Plantser: signposts that secretly became a full outline → return room to leap
