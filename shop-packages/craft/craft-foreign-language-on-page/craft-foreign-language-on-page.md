# Foreign language and code-switch on the page

How multilingual speech appears in English-dominant prose — inclusion, exclusion, intimacy, threat — without a language exam.

## Light

Job: put other-language speech on the page only when it does a dramatic job.

Contract: plot-critical info must still reach a non-speaker POV (or the reader) somehow.

Must-not-break:
- Choose the job first (texture, intimacy, exclude, status, humor, clash, realism)
- Long stretches: tag language, then fluent English of that speaker’s register
- Don’t mock via phonetic “foreigner” spelling 
- Native-tongue scenes → natural English of education/register, not broken English
- Consistency of how much foreign text appears

## Normal

**Delivery toolkit**
1. **Tag only** — “she said in French,” then fluent English (default for long stretches)
2. **Sprinkle** — short, guessable / widely known phrases; context carries meaning
3. **Untranslated + context** — surrounding beats teach enough
4. **Italics convention** — common for foreign words; don’t also overload italics for emphasis in the same book
5. **Code-switch mid-sentence** — mirrors bilingual speech; keep plot-bearing clauses clear

**Translate-as-fluent:** when characters speak *their* native tongue, render as natural English of their education/register. Broken English is for L2 speech *in* English.

**POV and fairness**
- Gloss what **this POV** would understand; confusion is a tool when POV is excluded
- Avoid using a real minority language as a disposable stand-in for another
- Respect competence and interiority in every language

| Failure | Fix |
|---------|-----|
| Essential plot only in untranslated speech | Gloss, tag, or paraphrase |
| Tourism vocabulary dump | Cut to job-bearing lines |
| L2 broken English for native-tongue scenes | Fluent translation of native speech |
| Italics war (emphasis + foreign + thoughts) | Reserve one convention |
| Stereotype comic foreigner | Status, Want, and wit in every language |

## Hard

**Sociolinguistic jobs (map to scene Want)**
| Function (wiki rationale) | On-page use |
|---------------------------|-------------|
| Solidarity / group identity | Private channel; in-group rapport |
| Attitude to listener (friendly, distant, ironic) | Status move without English paraphrase |
| Exclude / secrecy | Dramatic irony if reader knows; dread if reader doesn’t |
| Lexical need / topic | Technical term kept; surrounding English clarifies |
| Quote someone | Embedded other-voice authenticity |
| Soften or strengthen command | Register shift mid-conflict |

**Switch types (don’t over-engineer, but know the dial)**
- **Intersentential** — whole sentence/clause in other language (clearest for readers)
- **Tag-switching** — tag phrase / discourse marker (`you know` pattern in other tongue)
- **Intra-sentential** — mid-sentence mix (most “real”; highest readability cost)
- Literary scholarship also uses “code-switching” for styles that include multiple languages in novels (Chinese-American, Anglo-Indian, Latino traditions, etc.) — commit to a house style, not random sprinkle

**Register switching (same language)**
- Popular/sociolinguistic use: shift dialect/style/register by setting (e.g. AAVE ↔ more formal) — related craft in / 
- Public figures’ shifts read as inauthentic when motive is opaque — characters need a Want for the shift

**Fairness edge cases**
- Listener proficiency shapes patterns (wiki: switching influenced by addressee skill/preference) — use for power: expert talks over novice; ally slows and clarifies
- Borrowing a single loanword ≠ full code-switch — don’t italicize every taco
- Invented languages: naming/phonotactics in ; still obey plot-critical gloss rules
