# Jungian archetypes (character / myth craft)

Universal patterns as lenses — not rigid character classes.

## Light

Job: name recurring psychic/story patterns so cast and arc have mythic pressure without sticker-pack casting.

Contract: forms are empty until culture/life fills them; spark, don’t clone.

Must-not-break:
- Use as lens, not D&D class
- Shadow / Persona friction = drama fuel
- Antagonist often embodies denied Shadow
- Marketing “12 archetypes” ≠ pure Jung — label the difference
- Avoid casting women as Anima furniture

## Normal

**Core Jung figures (story-relevant)**

| Archetype | Craft angle |
|-----------|-------------|
| **Shadow** | Disowned traits; antagonist mirror; integration = growth, repression = blowback |
| **Persona** | Social mask vs private self |
| **Anima / Animus** | Inner contrasexual image; projection onto love/rivals |
| **Self** | Wholeness / individuation (often climax recognition) |
| **Mother / Father** | Nurture vs authority templates; complexes when real people mismatch |
| **Child** | Innocence, potential, orphan/hero origin |
| **Wise old man/woman** | Mentor / guide; also false sage |
| **Maiden** | Vulnerability / transition (don’t reduce characters to tropes) |
| **Trickster** | Disruption; comic or cosmic rule-breaker |

Event/motif archetypes also exist (birth, death, marriage, flood…). Number open-ended; they blend.

**Practice checklist**
- Pick one primary + one shadow flavor for a lead
- Let antagonist embody denied shadow
- Mentor = wise figure *or* failed wise figure
- Fill desire / fear / strategy / gift / trap only as brainstorm cards

**Marketing “12 archetypes”** (popular wizard set, not pure Jung)
Sage Innocent Explorer Ruler Creator Caregiver Magician Hero Outlaw Lover Jester Everyman

| Failure | Fix |
|---------|-----|
| Sticker on every cast member | One primary pressure + relationships |
| Shadow = only villain costume | Give lead a denied trait that costs |
| Anima as love-interest job | Inner conflict, not role assignment |
| Clone Enneagram/MBTI too | Spark then specificize  |

## Hard

**Individuation as arc metaphor**
- Archetypes seek actualization across life stages (parented → initiation → courtship → marriage → death prep)
- Story parallel: each act activates a new imperative; refusal stalls psyche/plot
- Self as wholeness goal ≠ “win the plot”; Climactic recognition can be integration without victory

**Projection & complexes (edge craft)**
- Anima/Animus projection onto partners/rivals: romance and rivalry both can be misrecognition plots — payoff = seeing the person, not the image
- Mother/Father complexes: authority/nurture wounds that distort present choices 
- Persona crack mid-book: public mask fails under Pinch/Third Plot Point pressure 

**School caution**
- Jungian analysis is psychology/myth theory — not a beat sheet; pair with GMC and scene turns
- Collective unconscious claim is theoretical; for fiction, treat recurrence as useful pattern language
- Cross-cultural motif lists invite stereotype if applied as ethnic costume — fill from character/world specifics
