# Second-person POV

Deepener for **you** as protagonist / narratee. Person / access / trust overview: . Distance / FID / register: .

## Light

Job: use “you” only when fusion, dissociation, or ritual address is the point — not as a cheap immediacy trick.

Contract: decide who is addressed (reader-as-role, named character, or self-to-self) and stick.

Must-not-break:
- One-sentence why this story *must* be “you” — else switch person
- Sensory floor early so the role has a body
- Situation over quirks (hyper-specific opinions raise rejection)
- Sympathy tether for hateable “you” (unreliability craft)
- Novel-length second person is rare; prove voice in a short stretch first
- Hybrid (chapters / letters / game UI only) needs a fair convention

## Normal

**When “you” earns the book**
- **Forced fusion** — inhabit the role; intensity / implication / alienation first alone won’t buy
- **Dissociation** — self narrating at a remove (denial, trauma echo, performance of self)
- **Instruction / recipe voice** — “how to” second person (Kincaid “Girl,” Moore how-to stories)
- Wrong tool when you only want “immediacy” — close first / deep third usually cheaper

**Who is speaking to whom**

| Pattern | Effect | Trap |
|---------|--------|------|
| Narrator = “you” = protagonist | Fusion / denial / self-watching | Reader rejects the assigned body |
| Narrator addresses a character-you | Intimacy, accusation, seduction, therapy | Second-person wallpaper |
| Imperative / how-to you | Ritual, power, cultural script | Joke wears out; no Want |

**Design checklist**
1. One-sentence why
2. Sensory floor early
3. Situation over quirks
4. Sympathy tether ( unreliable)
5. Tense + rhythm — present often pairs well; vary openings 
6. Exit plan for hybrids

**Length & hybrid**
- Full novel possible (*Bright Lights, Big City* lineage) but rare; ceiling is reader stamina
- Hybrid: confession, game interface, VR, therapy, letter — then release into first/third
- Games / interactive fiction habits ≠ novel habits

| Failure | Fix |
|---------|-----|
| Gimmick, no thematic job | Write the why-sentence; else switch person |
| Reader ejects from “you” | Soften quirks; raise situation stakes; shorten stretch |
| Past-tense “you walked” feels borrowed | Prefer present, or own memory-as-accusation |
| Pronoun-swapped close first | Exploit address: accusation, ritual, dissociation |
| Walls of “You…” | Vary openings; cut; hybridize |

## Hard

**Narratology edges (durable)**
- Second person can share first-person’s unreliability options — “you” recounts experience while adding distance (often ironic)
- Not always reader-as-hero: metafictional address (*If on a winter’s night a traveler*) vs immersion novel (*Bright Lights, Big City*)
- Modern hybrids: sections of Jemisin’s *The Fifth Season*; short fiction (Moore, Díaz); Michel Butor *Second Thoughts*
- **Near-misses that are not true second-person narrative:** addressed-reader novels with an implicit narrator (*The Reluctant Fundamentalist*); gamebooks / Choose Your Own Adventure; IF text that tells the user what they see — device of address ≠ novel second-person POV (Stross *Halting State* alludes to game style on purpose)

**Craft diagnostics**
- Symptom: reader says “that’s not me” → cause: quirks over situation, or forced fusion without bond → fix: soften assignment or shorten / hybridize
- Symptom: feels like first person with swapped pronouns → cause: unused address power → fix: accusation, ritual imperative, self-watching irony
- Couple with framed / nested tellers  when “you” is a narratee inside a teller’s scheme
