# Beta reader protocol

How to get usable reader-experience reports — not fake editorial diagnoses. AI cold-reader / anti-sycophancy protocols: .

## Light

Job: collect ordinary-reader experience so you can infer fixes — not outsource craft teaching.

Contract: ask for experience, not solutions; patterns beat outliers.

Must-not-break:
- Betas ≠ developmental editors or market analysts
- Stage the ask (early = big picture; late = confusion/emotion)
- 3–5 focused questions beat a critique dump
- Pet anxious questions last — see if they arise spontaneously
- Patterns > one loud dislike
- Timing: after structural self-passes, before line polish

## Normal

**Role boundary**
- Best at: where bored / hooked, who they rooted for, what confused them, ending satisfaction
- Worst at: three-act compliance, commercial prognosis, how to rewrite
- Say what you *don’t* need yet (typos, polish)

**Process hygiene**
- Set timing, delivery format (form / doc / summary), level of detail
- Optionally start with first 3 chapters before whole MS
- Cover sheet: title, genre, length, draft stage, feedback wanted / not wanted

**Core question bank (Friedman)**
- Overall impression? Liked most? Didn’t like?
- Grabbed at beginning? Lost interest where?
- Easy to follow? Confusing bits? Illogical / inconsistent?
- MC engaging? Keep track of who was who?
- Ending satisfying?

Prefer: “Where did you put the book down?” / “Which scenes dragged?” / cite chapter when confused.
Avoid leading with “Did you like X?” when you need experience of X.

| Failure | Fix |
|---------|-----|
| Asking for rewrite recipes | Ask experience only |
| One beta = law | Wait for patterns |
| Typos first on early draft | Scope the ask |
| Leading questions | Neutral experience prompts |

## Hard

**Expanded banks / framing**
- Optional genre asks: world believable? spice level? authenticity? comps? sequel interest? title preference?
- Grammar/format only if useful at that stage
- Put anxious pet questions **last**
- Timing: after structural + scene self-passes , before line polish — coherent story, still malleable

**Diagnostics from answers**
- Engagement drops → pacing / stakes / micro-tension (, )
- Confusion → POV clarity / transitions / info order
- Ending dissatisfaction → promise/payoff 
- Character dislike among lovers → don’t rewrite for the outlier
