# Conflict / GMC (Goal, Motivation, Conflict)

Debra Dixon’s GMC + internal/external conflict types.

## Light

Job: make want, why, and block crisp at book and scene scale so conflict drives change.

Contract: reader buys the why; opposition is real; each scene moves closer or farther from a goal.

Must-not-break:
- Goal specific, urgent, important, attainable
- Motivation simple, strong, focused — reader must buy it
- Conflict = why they can’t have it yet
- Antagonist needs GMC too
- Braid internal + external; don’t run only angst or only spectacle

## Normal

**GMC triad (Dixon)**
- **Goal (G)** — what the character wants
- **Motivation (M)** — why they want it
- **Conflict (C)** — what blocks the goal

Sentence skeleton:
- *[Name] wants [goal] because [motivation]. But [conflict], so [action to overcome it].*

Uses:
- Book-level chart per major character; re-chart when GMC shifts
- Scene-level GMC when a scene falls flat
- Antagonist GMC — convenient plots often = weak antagonist motivation
- Sagging middle / unblocked: unclear G, weak M, or thin C

**Internal × external matrix**

| | Internal | External |
|---|----------|----------|
| **Goal** | Emotional outcome wanted/needed | Physical / plot outcome |
| **Motivation** | Inner force (to be loved, belong, prove…) | Outside pressure (deadline, threat, duty) |
| **Conflict** | Inner block (fear, shame, Lie, competing desire) | Outer obstacle (rival, law, storm, clock…) |

Notes:
- Commercial fiction almost always needs clear **external** goal; internal adds layers
- Internal goals often steadier; if external goal changes, relate it to the old one
- External conflict ≈ plot; internal ≈ character arc
- Hero can be villain’s C and vice versa; romance partners often work at cross-purposes
- Some overall goals fail yet story satisfies if emotional/thematic payoff lands

**Motivation craft**
- Keep M simple and strong; complexity belongs in how conflict tests it
- Horror-basement test: “I’d never go down there” → unless puppy/child/truth is down there
- Backstory explains *why this M* without dumping it all upfront
- Align M with age, culture, genre expectations

**Conflict braid**
- **Internal** — opposing desires/beliefs inside; fuels development
- **External** — force beyond control between character and goals
- Strong stories: external pressure forces internal choice; internal change enables external action
- Stronger opposition → deeper character; antagonism must escalate or interest dies

| Failure | Fix |
|---------|-----|
| Flat scene | Clarify scene goal / why-now M / raise opposition |
| Convenient plot | Give opposing force a real GMC |
| Only spectacle | Add internal C tied to Lie/Want |
| Only angst | Externalize: force that makes inner struggle cost concrete |

## Hard

**Conflict types (novel checklist)**
Central conflict usually one primary type; others support without stealing the engine.

| Type | Axis | Notes |
|------|------|-------|
| Character vs Self | Internal | Moral dilemma, trauma, competing wants |
| Character vs Character | External | Opposing needs; villain or rival |
| Character vs Society | External | Law, custom, institution, norm |
| Character vs Nature | External | Weather, wilderness, disaster, animal |
| Character vs Technology | External | Machine, AI, scientific creation |
| Character vs Supernatural | External | Gods, ghosts, monsters; unequal field |
| Character vs Fate / Destiny | Internal+external | Accept/refuse destined role (some taxonomies fold into self/supernatural) |

Craft tips:
- Pick a conflict that fits theme/setting; make opposing force clear
- Don’t make the central conflict trivially easy
- Multiple types OK if one remains the through-line
- Theme often rhymes with conflict type

**Desire audit (advanced diagnostic)**
Main desire / unconscious desire / worst that can happen / even worse / who or what can bring that about.

**When goals fail successfully**
- Overall external goal can fail if emotional/thematic payoff lands — still chart the GMC so the failure is chosen under pressure, not forgotten
