# Builder: character

Fill-in cards and checklists for constructing people. Theory stays in craft files.

## Light

Job: fill cards that force Want, wound, and challengeable beliefs before drafting the person.

Contract: mains need beliefs that crash into plot; side characters can stay rough.

Must-not-break:
- Immediate Want + life-scale Want named
- Core beliefs challengeable (2–3)
- Negative / annoying trait that frictions with allies
- Want ≠ Need (except Flat arcs often Want ≈ Need)
- Antagonist needs a GMC too
- Copy 3–5 traits into the card — not a 140-trait dump into the MS

## Normal

**Order of use**
1. Quick attribute checklist
2. Generation template
3. Wound → shield → need (or Lie/Truth/Want/Need/Ghost)
4. GMC book + scene
5. Per-scene tracker

## Hard

**Contradiction / motivation generators**

- Contradiction: [role] holding [belief 1] and [belief 2] — rationalization → when it breaks → forced choice
- Motivation mapper: stated goal → say they want / actually want / need / afraid of getting / would destroy them if got
- Arc planner: across [N] chapters — misbelief → 3 turning points → almost-regress → final transformation

**Personality sketcher (messy → tool-ready)**
- Input: rich description → organized third-person sketch; dispassionate; no chat chrome

**Edge: arc-type mismatches**
- Flat arc: Want ≈ Need; world changes around them — don’t force Lie→Truth beat map
- Fall / Corruption: Truth abandoned — Ghost still installed the starting Lie
- Antagonist GMC must pressure protag Want — foil without private engine = cardboard
