# Tropes craft

Using genre/pattern tools without leaning on dead clichés; subversion; reader expectation contracts.

## Light

Job: reuse recognizable patterns intentionally — deliver the emotional promise, particularize the delivery.

Contract: if positioning sells a trope trajectory, the book pays its emotional signposts (or clearly sells a different ticket).

Must-not-break:
- Trope ≠ cliché (cliché = lazy/overused deployment)
- Using ≠ leaning (trope can’t replace characterization)
- Subverting some tropes usually reinforces others
- Twist ≠ break the genre ticket the reader bought
- Harm-as-spice “subversions” burn trust, not patterns

## Normal

**Trope vs convention vs cliché**

| Term | Sense |
|------|--------|
| **Genre trope / convention** | Recurring situation, archetype, structure, or object expected within a genre |
| **Motif** | Element recurring *inside one work*  |
| **Cliché** | Trope tired from overuse / lazy deployment — recombination restores appetite |

Academic “trope” (figurative language) ≠ this file’s genre-building-block sense.

**Tropes as reader contract**
- Shortcut exposition (hardboiled detective implies moral city, case structure, tone)
- Set emotional signposts readers invest in (HEA/HFN; fair-play clues)
- Create recognizable “game pieces” (hero, dragon, lost princess…)
- Developmental edit question: does the love story earn its ending type? Does the whodunnit leave breadcrumbs?

**Using vs leaning**
- **Using:** know the trope’s job; hit emotional beats; particularize; combine unusual sets
- **Leaning:** trope substitutes for character; plot armor; beats on schedule with no cost; outcome and moral predictable without tension
- Freshness = treatment, consequence, voice — not pretending patterns don’t exist (few basic story patterns)

**Subversion without betrayal**
1. **Set the pieces** so readers recognize the board
2. **Change the rule** that usually protects the pattern
3. Force reconsideration of who is “hero”

Other moves:
- Understand *why* the trope works before flipping it
- Introduce familiar signals early; twist gradually
- Gender-bent fairytale, villain-as-protagonist, perspective flip
- Recombine rather than void the contract (found family *of enemies*)

**Tropes that burn trust (avoid cluster)**
- Sexual assault as character development
- “It was all a dream” cheat endings
- Killing off all/only the diverse representation
- Deus ex machina savior 
- Characters reduced to sexualized parts

**Practical pass**
1. List 5–10 tropes you are *actually* shipping (cover, blurb, act-one signals)
2. For each: emotional promise / required signposts / how your version particularizes
3. Mark honor straight / subvert / refuse
4. Every subversion still delivers genre-adjacent payoff *or* you’ve repositioned the book
5. Cut leans: where a trope does the work a character choice should

| Failure | Fix |
|---------|-----|
| Bait-and-switch ending type | Reposition ticket or earn the sold promise |
| Predictable moral + outcome | Add cost; particularize character |
| Subversion = void contract | Reinforce other tropes; pay adjacent promise |
| Photocopy beats | Recombine; change consequence |

## Hard

**Simonds / WD board method (edge)**
- Set recognizable pieces (noble center, clear good/evil mapping…)
- Change the protective rule (e.g. realistic consequences / no plot armor)
- Complexity over team jerseys — reader must reconsider allegiance

**Theory note**
- Work is often praised when it skirts edges — plays with expectations rather than rigid adherence or total rejection
- Subverting some tropes usually **reinforces others**
- Cross-lane: genre obligations audit → ; romance-specific promises → 

**When to break “honor the sold trope”**
- Only when the book is clearly sold as a different ticket (literary tragic love ≠ category romance HEA)
- TV Tropes is encyclopedia, not mandate
