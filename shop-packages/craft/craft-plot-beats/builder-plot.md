# Builder: plot

Beat worksheets for commercial spines. Outline artifacts → . Premise → .

## Light

Job: fill a beat sheet that distinguishes Inciting vs 1PP and 2PP vs Final Battle — don’t collapse those pairs.

Contract: plot events carry character/flaw cost; climax answers the conflict question the Inciting asked.

Must-not-break:
- Inciting ≠ First Plot Point
- Second Plot Point / dark night ≠ Final Battle
- Midpoint shifts victim → warrior (or equivalent proactive turn)
- Inciting question answered at Climactic Moment
- Antagonistic force present/proxied at climax
- Romance: track Romance Arc beside external + internal

## Hard

**Romance dual-track**

If romantic leads: track Romance Arc beside external plot and each internal arc .

**Structure generators**

- Three-act breakdown: premise → per act opening state, 3–4 events, act-ending turn, emotional trajectory
- Midpoint reversal: first-half summary → 5 reactive↔proactive flips
- Tension escalation: central tension → 8 escalating events alternating external/internal
- Climax builder: 3 climax options testing arc + earlier lesson + external/internal

**Named-school crosswalk**
- Eight dots ≈ Weiland nine with Hook/Resolution explicit — don’t double-count Midpoint
- STC Fun & Games lives in Act 2a reactive quarter; Midpoint still required
- When percent fights feel: keep causal order; loosen timing within ~5%
