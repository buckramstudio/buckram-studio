# Builder: outline

Artifacts for designing (or reverse-engineering) the novel. Beat content → . Premise → .

## Light

Job: pick an outline artifact that matches temperament and situation — then fill it living, not forever.

Contract: outline serves draft; living docs revise earlier steps as characters teach you.

Must-not-break:
- Temperament match (plotter / pantser / plantser)
- Ending known enough for plantser tent poles
- Snowflake disasters map to act turns (D1≈end Act1; D2≈mid; D3≈end Act2)
- Reverse outline diagnoses change, not only “what happens”
- Don’t polish a zero draft into a fake first draft
- Scene spreadsheet: skip conflict-free rows

## Normal

**Temperament → artifact picker**

| Label | Prefer | Trap |
|-------|--------|------|
| Plotter | Beat sheet + scene list / Snowflake | Outline forever |
| Pantser | Draft → reverse outline | Structure debt |
| Plantser | Ending + 3–5 tent poles | Vague middle |

| Situation | Prefer |
|-----------|--------|
| Blank-page terror | Light signposts or STC foundation five |
| Planning kills spark | Draft → reverse outline |
| Lost in Act Two | Zero draft middle→end *or* Fun and Games→Midpoint |
| Mystery / multi-POV / series | Plotter tools + continuity bible |
| Edit letter / hopeless draft | Snowflake from step 1 *or* reverse outline + beat overlay |

**Character one-pager fields (step 3):** Name One-sentence storyline Abstract motivation Concrete goal Conflict Epiphany One-paragraph storyline

**Signpost / plantser card:** Ending Tent poles 1–5 Connective tissue left open

**Zero-draft brief**

- Goal: whole story exists; **tell**, don’t show
- Form: slapdash prose / bullets / friend-summary
- Heuristic: ~1 page per 1k eventual words (not law)
- Trap: polishing zero draft into a fake first draft

**Reverse-outline row (post-draft)**

| # | What happens | What **changes** | Keep / cut / move |
|---|--------------|------------------|-------------------|

Pair with .

**Scene spreadsheet columns (Snowflake 8):** `POV` `what happens` `page estimate` `chapter #` optional GCD/Sequel stage — reorder freely; ~100 scenes common.

| Failure | Fix |
|---------|-----|
| Outline forever | Draft from step 8 rows |
| Vague middle | Tent poles or Fun & Games→Midpoint |
| Reverse outline = plot summary only | Force “what changes” column |

## Hard

**School hybrids that change decisions**
- Snowflake → STC/Weiland overlay at step 8: map scenes to beats without restarting step 1
- Pantser mid-book: reverse outline + beat overlay beats restarting Snowflake from zero
- Series / mystery: plotter tools + continuity bible — plantser tent poles alone under-serve fair-play

**Advanced diagnostics**

| Symptom | Cause | Tool |
|---------|-------|------|
| Spark dies in outline | Over-specified connective tissue | Plantser card; leave middle open |
| Structure debt after pants | No reverse outline | Post-draft change map |
| Act Two fog | No tent poles / disasters | Zero draft middle→end or Snowflake step 2 disasters |

**When to break Snowflake order:** cycle back from 7 to 1–6 when characters teach you; skip step 9 if conflict-free; never treat steps as sacred if draft is teaching harder truths.
