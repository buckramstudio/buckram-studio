# Narrative structures (cross-tradition)

Models for how stories are ordered — Western three-act, monomyth, East Asian four-act, Freytag, comedy/tragedy shapes, linear vs nonlinear.

Companion: (commercial eight-point), (how to apply).

## Light

Job: pick an ordering model that matches the story’s engine — conflict pyramid, twist-fruition, or pattern alternatives — then hit the early commitment mark.

Contract: by ~20–30% the reader has hints of goal, stakes, obstacles, *and* internal pressure; the chosen shape’s late turns still answer the opening dramatic question (or earned reframe).

Must-not-break:
- Name the model you are using (or hybrid) — don’t mix unmarked
- End-of-beginning / point of no return lands with cost
- Internal issues complicate the external goal (not plot-only)
- Nonlinear needs foreshadowed time logic, not random shuffle
- Kishōtenketsu and conflict-pyramid are different promises — don’t market one as the other

## Normal

**Three-act (Field-style screen popularization)**

| Act | Job |
|-----|-----|
| **1 Setup** | Exposition: characters, relationships, world. **Inciting incident/catalyst** confronts protagonist. **First plot point** ends the act — life can’t go back; raises the **dramatic question** answered at climax |
| **2 Confrontation** | Protagonist tries to fix the problem; situations worsen. Lacks skills/awareness → learns → **character arc**. Mentors/allies help. Ends at second plot point |
| **3 Resolution** | Tensions peak; climax answers dramatic question; new sense of who characters are |

Dramatic question examples: Will X recover the diamond? Win the love interest? Catch the killer?

**History note:** Often mis-attributed to Aristotle; he argued complication + dénouement split by *peripeteia*. Donatus (4th c.) described three parts; Freytag (1863) fed later three-/five-act diagrams.

**Freytag / classic Western shape**
Freytag: Introduction → Rise → Climax → Return/Fall → Catastrophe. Later diagrams: Exposition → rising action → climax → falling action → dénouement.

**Hero’s journey (monomyth)**
Campbell (*Hero with a Thousand Faces*): adventure → crisis victory → return transformed. Often **Departure / Initiation / Return**. Not every story uses all 17 stages; order can vary. Heavily criticized by folklorists (selection bias); still useful as a planning checklist. Vogler compresses for writers.

Campbell Departure (examples): Call to Adventure Refusal Supernatural Aid Crossing the First Threshold Belly of the Whale

Initiation (examples): Road of Trials Meeting with the Goddess Temptress Atonement with the Father Apotheosis Ultimate Boon

Return (examples): Refusal of Return Magic Flight Rescue from Without Crossing Return Threshold Master of Two Worlds Freedom to Live

**Vogler-style beat names:** Ordinary World Call Refusal Mentor Threshold Tests/Allies/Enemies Inmost Cave Ordeal Reward Road Back Resurrection Return with Elixir

**Kishōtenketsu (起承転結)**

| Part | Rough job |
|------|-----------|
| **Ki / 起** | Introduction — characters, era, setup |
| **Shō / 承** | Development — expand without major twist yet |
| **Ten / 転** | Twist / reversal / biggest turn (yama) — often holds back a major element; can shift genre feel |
| **Ketsu / 結** | Conclusion / consequence / fruition |

Often described as **not conflict-centered** the way Western three-act is — but stories can still contain conflict (*Parasite* cited). Asymmetry: big element delayed to act 3 of 4. Also used in poetry, essays, yonkoma, game level design. English deep-dive: Henry Lien (*Spring, Summer, Asteroid, Bird*).

**Frye comedy / tragedy shapes**
- **U-shape (comedy):** equilibrium → disaster → new stable condition
- **Inverted U (tragedy):** rise to prominence → disaster
- Seasonal myths (*Anatomy of Criticism*): spring comedy summer utopia fall tragedy winter dystopia

**In medias res**
Open in the chronological **middle** of the plot (Horace: snatch the listener *in medias res*, not *ab ovo* “from the egg”). Fill backstory later via dialogue, flashback, nonlinear reveal. Epic convention (*Iliad*, *Odyssey*); common in modernist fiction and film noir. Contrast: *ab initio* / chronological start.

**Linear vs nonlinear**
- **Linear:** events largely chronological
- **Nonlinear / disrupted:** out of order or non-causal presentation (Alison: spirals, waves, meanders)
- **Interactive narration:** one story; user works to unlock next piece
- **Interactive narrative:** branching choices → alternate developments/endings

**25% mark — go deeper than the label**
Names differ (Catalyst / First Plot Point / End of Beginning); **function** ≈ point of no return (~20–30%). By then readers need at least hints of:

1. Story goal(s) + stakes
2. Main conflicts / antagonists / obstacles
3. **Internal issues** complicating the goal (false beliefs, wounds) — often missing from external-only beat sheets

Without internal hints: external conflict may feel thin; struggle feels “plot needs them to”; negative traits look permanent; self-destructive assumptions lose sympathy. Fix: few words of wound/backstory by ~25% so readers stay in the character’s corner.

| Failure | Fix |
|---------|-----|
| Label soup, no function | Map each beat to dramatic question + cost |
| External-only sheet | Add internal hint by ~25% |
| Kishōtenketsu sold as three-act | Honor delayed *ten*; don’t force mid-act duel |
| Nonlinear confusion | Foreshadow time logic; fewer unmarked jumps |
| Monomyth checklist theater | Cut unused stages; keep only pressure moves |

**Monomyth critique (when to distrust the map)**
- Folklorist critique: selection bias — Campbell’s pattern fits stories chosen to fit it
- Useful as optional checklist, not universal law; non-Western and literary patterns may refuse Departure→Return
- If stages feel bolted on, drop them — function beats (call, threshold cost, ordeal, return change) matter more than names

**Kishōtenketsu vs conflict pyramid (decision fork)**
- Pyramid: escalation through opposition; midpoint often raises stakes via reversal
- Kishōtenketsu: development can expand without major opposition until *ten*; payoff is consequence/fruition of the twist
- Hybrid possible (*Parasite*-style conflict inside four-part rhythm) — declare which reader promise dominates
- Also used outside novels (yonkoma, essays, game levels) — transfer the *ten* logic, not forced sword fights

**Nonlinear advanced diagnostics**
| Symptom | Cause | Pass |
|---------|-------|------|
| Reader lost on “when” | Unmarked jumps | Consistent tense/space signals; fewer layers |
| Emotional flatness | Order serves puzzle only | Re-order so each reveal changes Want/Need |
| Backstory overwhelms | Complex past + complex present | Simplify one track  |
| Pattern novel (spiral/meander) read as broken plot | Wrong shelf promise | Signal aesthetic early; don’t fake three-act marketing |

**When to break the rule**
- Tragedy may refuse comedy’s U-recovery; literary endings may refuse neat dénouement (, )
- In medias res can open on climax residue if the dramatic question is *how we got here / what it costs now*
- Interactive branching changes “structure” into graph design — track dramatic question per path
