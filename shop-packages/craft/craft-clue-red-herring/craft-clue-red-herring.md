# Clue plant and red herring craft

Fair misdirection for any puzzle plot — mystery shelf engine stays in .

## Light

Job: plant truth early in disguise; mislead without cheating the co-detective contract.

Contract: every clue the solver uses was available to the reader; reveal recontextualizes known facts.

Must-not-break:
- No vital fact only at parlor scene
- Red herrings plausible and later explained
- Lucky accidents / unaccountable intuitions cheat (Knox)
- Detective declares discovered clues
- State puzzle vs thriller contract honestly

## Normal

**Fair-play baseline**
- Reader as co-detective; curiosity satisfied at end from elements clearly presented
- Reveal recontextualizes what the reader already knows
- Victim matters; motive human (inbox checklist)

**Clue economy**
1. Write the **solution first**
2. List **3–7 true clues** in discovery order
3. For each: misleading interpretation at plant time + earliest fair-solve window
4. Plant linchpin early as casual detail; meaning flips late
5. **Clue audit:** every fact the solution needs appears before the reveal

Suspect grid (cast-based): Motive / Means / Opportunity + a **personal secret** that explains shady behavior without being the answer.

**Red herrings that play fair**
- True twist → ~3 fair herrings, each with subtle **wrongness**
- Eliminate false solutions on-page
- Gossip/noise can bury truth — still plant the true bit in the noise
- Hidden passage / twin: prepare (Knox limits)

**Puzzle vs thriller lean**

| Lean | Reader job | Clue duty |
|------|------------|-----------|
| Mystery | Co-detect | Strict fairness |
| Thriller | Endure / race | Fair-*enough*; dread may outrank puzzle |
| Hybrid | Both | State which contract; don’t bait mystery then cheat |

| Failure | Fix |
|---------|-----|
| Withheld vital fact until reveal | Move into earlier disguise |
| Herring never explained | Pay off or cut |
| Detective withholds declared clues | Declare discoveries |
| Bait-and-switch gotcha | Rebuild ledger or drop mystery promise |

## Hard

**Knox Decalogue (ops-relevant extract)**
1. Criminal mentioned early; not someone whose thoughts the reader has shared
2. No supernatural agencies (as solution)
3. At most one secret room/passage
4. No undiscovered poisons / appliances needing long end explanation
5. Avoid exoticized stock villains (period wording racist — modern: no stereotype shortcut culprit)
6. No lucky accidents / unaccountable correct intuitions
7. Detective must not be the criminal
8. Detective must declare discovered clues
9. Watson-sidekick: don’t hide their thoughts; intelligence slightly below average reader
10. Twins/doubles only if prepared

**Van Dine**
- 1928 companion fair-play code (lengthier); same spirit — reader as co-detective; no cheap withholding
- Use as audit checklist alongside Knox; full twenty not required on page if spirit held

**Advanced diagnostics**
| Symptom | Cause | Tool |
|---------|-------|------|
| “I never could have solved it” | Fact at reveal only | Move plant |
| “Too obvious at 40%” | Linchpin unmarked but uncamouflaged | Add misleading frame; keep fairness |
| Sidekick holds secret solve | Knox 9 breach | Declare or share thoughts |
| Impossible crime handwave | Physics unexplained | |
