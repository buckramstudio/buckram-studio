# Builder: Theme / motif card

Theme argument + motif ledger (fill-in). Theory → .

## Light

Job: turn topic stickers into a debatable Truth argued by choice + cost, carried by motifs that flip.

Contract: theme ≠ topic; prove via climax choice, not sermon lines.

Must-not-break:
- Thematic question is debatable
- Working Truth is an argument, not a slogan
- Protagonist Lie named
- Motifs return with changed context (who notices, intensity, irony)
- No caption dialogue (“the crow means…”)
- If removable without changing climax choice → decoration, not theme
- Supporting cast disagrees without unanimous conversion

## Normal

**Order of use**
1. Theme contract
2. Lie ↔ Truth beat anchors
3. Thematic square (cast pressure)
4. Motif ledger
5. Dilemma → theme bridge
6. Anti-sermon audit
7. One-line theme card for packets

## Hard

**Ending modes that change the card**
- Embrace Truth Reject Truth Pyrrhic — controlling idea line must match paid choice
- Disillusionment / Fall arcs: Truth may be bitter; don’t force positive slogan

**Cross-lane**
- Romance: Truth often about worthiness / trust — couple Black Moment must pressure Lie 
- Mystery: thematic aftertaste optional; don’t let sermon replace fair-play solution

**Advanced diagnostics**

| Symptom | Cause | Fix |
|---------|-------|-----|
| Theme only in dialogue | No dilemma bridge | Hard fork with costs |
| Cast agrees too soon | Missing contrary/negation | Fill thematic square |
| Motifs captioned | Author anxiety | Show flip; cut explanation |
