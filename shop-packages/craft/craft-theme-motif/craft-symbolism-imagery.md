# Symbolism & imagery systems

Earned symbols and networked images. Theme argument / anti-sermon: . Chekhov / foreshadow: . Setting as symbol: .

## Light

Job: let concrete images carry abstract charge without decoder-ring captions.

Contract: reader feels the question; professors name it later — meaning arrives from context under pressure.

Must-not-break:
- Symbol can appear once; motif must repeat
- Prefer organic discovery → amplify in revision over thesis-object on page one
- Never paragraph-explain “the crow means danger”
- Literal first, symbolic later often strongest
- Specific > generic (oleander beats “a rose for love”)

## Normal

**Working distinctions**

| Term | Job | Recurrence |
|------|-----|------------|
| **Theme** | Abstract argument the story proves | Story-length claim |
| **Symbol** | Concrete stands for abstract | Can appear once |
| **Motif** | Recurring concrete that accumulates charge | Must repeat; pattern teaches |

Write Practice: motif tied tightly to plot/theme via repetition; one-off dove can be a local symbol. WD: motif once = atmosphere; motif inching chapter by chapter = message without caption. Repeated symbol *becomes* motif.

**Earning a symbol**
- Charge from **context under pressure** — same object before/after betrayal means differently
- Inside joke with the reader: layer they can catch without a decoder ring
- Anti-patterns: symbol dictionary dropped in; every prop screaming meaning; weather captioning emotion every beat

**Motif networks (systems, not one mascot)**
1. Single object returning with shifting emphasis
2. Related cluster (colors in *Gatsby*: green longing, white false purity, gray ash)
3. Seeming-unrelated set that rhymes thematically (crow + shadow + window)

Network craft:
- Vary who notices, distance, intensity, completeness/brokenness
- Space returns: too dense → obvious; too sparse → forgotten
- Let motifs **converse** — one image undercutting another
- Tie returns to structural beats without captioning the beat
- Sensory channels: smell, hymn line, gesture — not only visual

**Imagery systems (prose-level)**
- Pick a governing domain (maritime, clinical, agricultural, liturgical, mechanical) that fits worldview
- Metaphors inside that domain reinforce voice; random mixed domains dilute
- Multi-POV: allow different domains per POV
- Escalation: figurative language denser or more distorted under stress

| Failure | Fix |
|---------|-----|
| “This symbolizes…” line | Delete; prove via context |
| Image only allegorical | Give it literal scene work |
| Too many networks | Keep 1–2; demote the rest |
| Mixed metaphor domains | Lock a governing field |

**Draft → revision workflow**
1. Draft for story; note images that recur unbidden
2. Name theme claim tentatively 
3. Choose 1–2 networks; cut the rest so pattern breathes
4. Plant earlier, pay off later; deepen mid-book returns
5. Final pass: delete author glosses; climax doesn’t need symbol explained aloud

## Hard

**Bell column method (revision)**
Three columns — standout sensory details main characters significant settings → find 2–3 strong connections → weave as symbols/motifs.

**Classic charge examples (craft, not lit-crit dump)**
- Eckleburg eyes — omniscience/moral watch felt before named
- Green light — desire already behind him
- *A River Runs Through It*: water as family/religion practice → “I am haunted by waters”
- Specificity: oleander (tough, attractive, poisonous) for controlling mother; tomato “groping for light” for the child (*White Oleander* via Bell)

**Mastery checks**
- Remove the “this symbolizes…” line — does meaning still arrive?
- Can a smart reader disagree about exact meaning and still feel the charge? (Good — symbols aren’t math.)
- Cross-lane: setting used as symbol → ; theme argument →
